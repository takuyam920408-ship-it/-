# 【楽曲提供：箕輪レコーズ】動画ピックアップ

概要欄に「【楽曲提供：箕輪レコーズ】」と書かれている自分のチャンネルの動画だけを抽出し、
スプレッドシートに URL 一覧として書き出す Google Apps Script。

対象シート:
https://docs.google.com/spreadsheets/d/1y9KR9SwZTlKfHr0J8AirIaYC1aT38s6LfxU79qAJy7U/edit

## セットアップ手順

1. 上記スプレッドシートを開く
2. メニュー「拡張機能」→「Apps Script」
3. `pickupMinowaRecords.gs` の中身を丸ごとコピーして貼り付け、保存
4. 左メニュー「サービス」→「+」→ **YouTube Data API v3** を追加（識別子は `YouTube` のまま）
5. 関数 `pickupMinowaRecords` を選んで実行 → 初回のみ権限承認を許可

実行すると「箕輪レコーズ」というシートが作られ（既にあれば上書き）、
No. / 動画URL / タイトル / 公開日 の 4 列で新しい順に並びます。

## 注意点

- スクリプトを実行する Google アカウントが、対象 YouTube チャンネルのオーナーである必要があります。
  ブランドアカウントの場合は、そのチャンネルに切り替えた状態のアカウントで実行してください。
- 非公開・限定公開の動画も、自分のチャンネルであれば対象に含まれます。
- 判定は正規表現 `/楽曲提供\s*[：:]\s*箕輪レコーズ/` で行っています。
  半角コロンや括弧なしの表記ゆれも拾いますが、条件を厳密にしたい場合は
  `MATCH_PATTERN` を `/【楽曲提供：箕輪レコーズ】/` に変更してください。
- 動画本数が非常に多い場合、Apps Script の実行時間上限（6分）に達することがあります。
  その際はご連絡ください。分割実行版に書き換えます。

## 定期更新したい場合

Apps Script の「トリガー」から `pickupMinowaRecords` を
日次・週次などで実行するように設定すれば、シートは自動で最新化されます。

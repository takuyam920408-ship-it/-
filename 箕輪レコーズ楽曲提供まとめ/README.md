# 【楽曲提供：箕輪レコーズ】動画ピックアップ

概要欄に「【楽曲提供：箕輪レコーズ】」と書かれている自分のチャンネルの動画だけを抽出し、
スプレッドシートに URL 一覧として書き出す Google Apps Script。

対象シート:
https://docs.google.com/spreadsheets/d/1y9KR9SwZTlKfHr0J8AirIaYC1aT38s6LfxU79qAJy7U/edit

## セットアップ手順

1. 上記スプレッドシートを開く
2. メニュー「拡張機能」→「Apps Script」
3. `pickupMinowaRecords.gs` の中身を丸ごとコピーして貼り付け、保存（Ctrl+S / Cmd+S）
4. 左メニュー「サービス」→「+」→ **YouTube Data API v3** を追加（識別子は `YouTube` のまま）→「追加」
5. 上部の関数プルダウンで **`checkChannel`** を選んで「実行」
   - 初回のみ権限承認を求められる
     →「権限を確認」→ アカウント選択 →「詳細」→「（プロジェクト名）に移動」→「許可」
   - 実行後、下部のログに **チャンネル名 / チャンネルID / 公開動画数** が出る
   - ここが「バズらないと」のチャンネルになっていることを必ず確認する
6. 合っていれば、関数プルダウンを **`pickupMinowaRecords`** に変えて「実行」

実行すると「箕輪レコーズ」というシートが作られ（既にあれば上書き）、
**No. / 動画URL / タイトル / 公開日** の 4 列で新しい順に並びます。
最終行の下には「該当◯本 / 全◯本」と更新日時が入ります。

## つまずいたときは

### `checkChannel` が別のチャンネルを表示する / エラーになる
ブランドアカウントでチャンネルを運用している場合によく起きます。
YouTube Studio →「設定」→「チャンネル」→「詳細設定」で確認できる
`UC` から始まるチャンネルIDを、スクリプト冒頭の

```js
var CHANNEL_ID = '';
```

に貼り付けて（例: `var CHANNEL_ID = 'UCxxxxxxxxxxxxxxxxxxxxxx';`）から再実行してください。

### 該当0本になった
`pickupMinowaRecords` のログに、実際の概要欄の冒頭300文字が3本分出力されます。
そこで表記を確認してください。想定と違う書き方（半角括弧、「楽曲提供」の前に改行が入る等）
であれば、スクリプト冒頭の `MATCH_PATTERN` を実際の表記に合わせて調整します。

判定は現在 `/楽曲提供\s*[：:]\s*箕輪レコーズ/` です。
半角コロンや括弧なしの表記ゆれも拾う、やや緩めの設定にしてあります。
厳密に `【楽曲提供：箕輪レコーズ】` だけに限定したい場合は
`MATCH_PATTERN` を `/【楽曲提供：箕輪レコーズ】/` に書き換えてください。

### 「実行時間の上限を超えました」と出た
Apps Script の実行上限は6分です。動画本数が非常に多い場合のみ発生します。
その際は連絡をもらえれば、分割実行版に書き換えます。

## 補足

- 非公開・限定公開の動画も、自分のチャンネルであれば対象に含まれます
  （`CHANNEL_ID` を指定した場合は、そのチャンネルのオーナーとして実行していれば同様）
- ショート動画もアップロード一覧に含まれるため、対象になります

## 定期更新したい場合

Apps Script 左メニューの「トリガー」から `pickupMinowaRecords` を
日次・週次などで実行するように設定すれば、シートは自動で最新化されます。

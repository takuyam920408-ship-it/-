# 新チャンネル（芸能ビフォーアフター）

ベンチマーク3チャンネルの台本構成と動画デザインを分析して、型にしたフォルダです。チャンネル名はまだ決まっていません。

| | ベンチマーク | URL |
|---|---|---|
| ① | こっそり速報 | https://youtube.com/@kossori_sokuhou |
| ② | オトナの夜ふかしch | https://youtube.com/@otonano_yofukashi |
| ③ | 男子の味方ch | https://youtube.com/channel/UCvj4RAM3BKe0NHqrk3O0Vag |

| ファイル | 中身 |
|---|---|
| ベンチマーク3ch共通点.md | 3チャンネルの共通点・違い、冒頭の作り方、起承転結、画像の選び方、タイトルのデータ、入れない方がいいもの |
| 1位動画の分解.md | 3チャンネルの1位動画の分解（①1位は全7カットの秒数・写真・テロップまで）、同じ型で伸びなかった動画との比較 |
| ベンチマーク①こっそり速報.md | ①の詳しい数字と、伸びた理由・伸びなかったもの |
| 台本の型.txt | 起承転結、冒頭の文の型、写真の選び方、3つの型（昔→今／比較・逆転／話題・ニュース）、言い回し集、タイトル・概要欄・タグの型、記入用テンプレ |
| 編集デザインの型.txt | 画面の配置・色・文字・カット割り・音、②③との違い |
| デザイン見本.png | 本編のレイアウト見本（写真部分はグレーの仮置き） |
| 冒頭画面3パターン.png | 冒頭のタイトル画面の3パターン見本 |

台本を作るときは、「台本の型.txt」の一番下にある記入用テンプレをコピーして使ってください。

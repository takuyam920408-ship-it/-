# 新チャンネル（芸能ビフォーアフター）

ベンチマーク「こっそり速報」（@kossori_sokuhou）の台本構成と動画デザインを型にしたフォルダです。チャンネル名はまだ決まっていません。

| ファイル | 中身 |
|---|---|
| ベンチマーク分析.md | 数字と、伸びている理由・伸びなかったもの |
| 台本の型.txt | 3つの型（昔→今／比較・逆転／話題・ニュース）、言い回し集、タイトル・概要欄・タグの型、記入用テンプレ |
| 編集デザインの型.txt | 画面の配置・色・文字・カット割り・音 |
| デザイン見本.png | レイアウトの見本（写真部分はグレーの仮置き） |

台本を作るときは、「台本の型.txt」の一番下にある記入用テンプレをコピーして使ってください。

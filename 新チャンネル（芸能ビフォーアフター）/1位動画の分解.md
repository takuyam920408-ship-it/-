### 1-4. 細かい作り方
- **1カット＝写真1枚＝テロップ2行**（上→下）。下テロップは、カットが始まって約2秒後に出る
- **公開カットだけ下テロップを2つ**（「誰やねん」「別人すぎやろ」）。一番驚かせたい所でツッコミを増やす
- カットの長さは3.7〜3.8秒でそろっていて、公開カット（4.7秒）と最後のカット（6.5秒）だけ長い
- **昔の写真は4枚すべて別の写真**。同じ写真の使い回しなし
- 昔は黒髪・前髪あり、今は茶色のロングヘア・赤い口紅。**モザイク越しでも色と髪型の変化が分かる**
- 正体（グループ名）は公開の**後**に出す。先に出すと、知っている人には答えが分かってしまう
- 概要欄はていねい語で、生年月日・出身・日本での活動・デビュー日・練習生期間を書いている。タグは名前（アンナ・田中杏奈）・グループ名（MEOVV・ミヤオ）・事務所・KPOP

### 1-5. 同じ型で40万回だった動画との比較

同じチャンネルの「元から美人が韓国行ったらこうなるｗ」（NiziUのミイヒさん、9/24投稿、40万回）は、タイトルも構成もほぼ同じです。差が出たところを並べます。

| | 579万回の動画 | 40万回の動画 |
|---|---|---|
| 冒頭の昔の写真 | 明るいテレビのキャプチャ。名前テロップ入り | 暗めの自撮り動画のキャプチャ |
| 冒頭の今の写真（モザイク） | 茶色のロングヘア・赤い口紅。**昔との差がモザイク越しでも分かる** | 黒髪・頬に手を当てたポーズ。**昔と色が似ていて差が分かりにくい** |
| 昔の写真 | 4枚、すべて別の写真 | 2枚（オーディション映像のキャプチャ） |
| 1カットのテロップ | 2行（公開カットだけ3行） | 3行のカットが多い |
| 名前を出す時 | 日本名は公開の直前（13秒）、グループ名は公開の後（19.5秒） | 本名を5秒で出し、グループ名は21.5秒 |
| 締め | 「元から可愛かったのにな」（タイトルを回収） | 「ワイは日本におった頃の方が好きやわ」 |
| 投稿 | チャンネル17日目 | 37日目（同じ型の2本目） |

**579万回になった理由（推測を含む）**
1. **モザイク越しでも変化が見える冒頭画像**（事実：画像の差）。見る前から「何か大きく変わった」と分かる
2. **主役の知名度がちょうどいい**（推測）。日本では「田中杏奈」を知らない人が多く、公開で本当に驚ける。ミイヒさんは日本でも有名で、答えを知っている人が多い
3. **昔の写真を何枚も見せて「昔も可愛い」を納得させてから公開**（事実：枚数の差）
4. **最後の一言がタイトルを回収して、気持ちよく終わる**（事実：締めの差）
5. 1本目だったので、同じ型を見飽きた人がいなかった（推測）

## 2. ②1位「青木マッチョ、風吹ケイを振った理由ヤバいやろw」（410万回）

| | 地点 | 画面 | テロップ |
|---|---|---|---|
| 起 | 冒頭 | 左に男性（青木マッチョ）→ 赤い→ → 右にモザイクの女性 | さすが有村架純を自宅に入れた漢…（マゼンタ） |
| 承 | 約30% | マスコットの区切りカード | ほな、イクで！ |
| 転 | 約50% | 風吹ケイさんの写真 | 上：グラドルの風吹ケイが2年惚れてた相手（緑）／下：2023年のライブで一目惚れ そこからずっとや（オレンジ） |
| 結 | 約80% | 2枚を上下に：自宅で猫とくつろぐ青木マッチョ／同じ部屋に座る有村架純 | そもそもこの人 自宅に有村架純呼んでるからな（緑） |

**作り方のポイント**
- タイトルは「振った理由ヤバいやろ」で**理由を知りたくさせる**。冒頭の文は、その答えを**謎めいた形で先に出す**（「有村架純を自宅に入れた漢…」）。見た人は「どういうこと？」となる
- 主役は男性で、**有名な女性2人との関係**がネタ（冒頭の文の「有名人の関係型」）
- 最後の一言「自宅に有村架純呼んでるからな」が、冒頭の「有村架純を自宅に入れた漢」を回収して終わる
- テロップは1枠3行で大きい。上と下で色を変える（緑とオレンジ）

## 3. ③1位「【悲報】本田翼さん(34)、そろそろ限界か…」（140万回）

| | 地点 | 画面 | テロップ |
|---|---|---|---|
| 起 | 冒頭 | 白いワンピースの写真に**まるごとモザイク** | 【悲報】本田翼さん(34) そろそろ限界か…（マゼンタ） |
| 承 | 約30% | 配信のスクショ（すっぴん風） | 気抜いたら〇〇みたいになるの怖すぎるやろ（緑） |
| 転 | 約50% | テレビ番組のキャプチャ（番組のテロップ入り） | ぐるナイの時は結構危うかったよな（オレンジ）→ うーん、このw（赤・重ねて表示） |
| 結 | 約80% | **冒頭でモザイクをかけていた写真をそのまま公開** | なんでや大人の色気増してきたやろ😡（緑） |

**作り方のポイント**
- タイトルと冒頭で「限界か…」と**悪い方に振る**
- 途中は「確かに限界かも」と思わせる写真（気を抜いた配信・昔の番組）を出す
- 最後に**冒頭のモザイク写真を外して**、「大人の色気増してきたやろ」と**褒めでひっくり返す**。答えを最後まで取っておく形
- テロップに絵文字を使う（😡）。前のテロップに次のテロップを重ねて積む
- 注意：承の「〇〇みたいになる」は別の実在の人と比べてけなす表現なので、まねしない方がいい

## 4. 3本の1位に共通すること

1. **最後の一言が、冒頭の文を回収する**
   - ①「元から可愛い**のに**」→「元から可愛かった**のにな**」
   - ②「有村架純を自宅に入れた漢…」→「自宅に有村架純呼んでるからな」
   - ③「そろそろ限界か…」→「大人の色気増してきたやろ」（ひっくり返して回収）
   → 見終わったときに「そういうことか」とスッキリする。もう一度見たくなり、コメントも書きたくなる
2. **答えは冒頭でモザイクにして、動画の中で必ず見せる**
   ①は真ん中（48%）で公開、②③は最後（約80%）で答えを出す
3. **冒頭の文は3行以内で、最後が「ｗ」か「…」**
4. **冒頭の画像だけで「何か大きく変わった／何かある」が伝わる**（モザイク越しでも色・髪型・人物の差が見える）
5. **主役1人＋知っている名前1つ**（①田中杏奈→MEOVV、②有村架純、③本田翼）
6. **途中は2〜3枚の写真とツッコミで引っぱる**（①は昔の写真を3枚、②は風吹ケイ、③は配信と番組）

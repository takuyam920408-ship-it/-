# ベンチマークの音の調べ方（声の種類と効果音）

クラウドではYouTubeの動画を再生できず、Claudeは音を聞けない。そこで、Macの Chrome でベンチマークのショートを**ふつうに再生しながら**、ブラウザの音の解析機能で「いつ・どのくらいの高さの音が鳴ったか」「声の高さ」を数字で記録する。動画や音そのものは保存しない（ダウンロードしない）。

## Macでやること（Claude in Chrome）

1. Chrome でベンチマークのショートを開く（例：①1位 https://www.youtube.com/shorts/4dE4-REUWzE 、①2位 https://www.youtube.com/shorts/exDUKzhdhvw 、②1位 https://www.youtube.com/shorts/-fcrWwaFzwk 、③1位 https://www.youtube.com/shorts/x7wQt07CXAE ）
2. ページで1回クリックして音が出る状態にしてから、`probe.js` の中身をそのページで実行する（Claude in Chrome の JavaScript を実行する機能）。動画が最初から1回再生され、終わると `<動画ID>_oto.json` がダウンロードされる
3. ダウンロードされた JSON を、このフォルダの `kekka/` に入れてコミットしてプッシュする（数字だけで、音は入っていない）
4. 3本以上やる（①を2本、②③を1本ずつが目安）

## クラウドでやること

```
python3 analyze.py kekka/<動画ID>_oto.json [../../スクラッチの字幕.vtt]
```
- 声：話している区間ごとの声の高さと、高さで分けた声の種類
- 音の出だし：効果音らしいもの（いつ・長さ・高い音か低い音か）。テロップが出る時刻（コマ画像・字幕）と照らして、どこで鳴るかを決める
- BGM：声がないところにも音が鳴っているか

分かったことは `remotion-kotaeawase/scripts/se.py`（効果音の作り方）と、spec の `sfx`（どこで鳴らすか）に反映する。

## 自分の動画で確かめる

`python3 oto_from_file.py ../remotion-kotaeawase/out/<id>_kansei.mp4 自分.json` で、自分の動画も同じ形の数字にできる。ベンチマークと並べて、効果音の場所や音の大きさを比べる。

## 分かっていること（2026-11-08）

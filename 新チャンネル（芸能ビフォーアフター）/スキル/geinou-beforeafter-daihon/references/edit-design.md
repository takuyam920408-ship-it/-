# 編集デザインの型

座標は 1080×1920 の画面での位置（x＝左から、y＝上から、単位px）。ベンチマーク①こっそり速報の画面を測った値が基本で、②③との違いは最後にまとめた。
新チャンネル用に作ったデザイン（タイトル画面A・B・C、本編4種類の見本）：https://claude.ai/artifact/2rdz4rK7kPS6oo3E3BXKHW

## 画面全体
- サイズ：1080×1920（縦）
- 背景：**オレンジの放射線**（濃 #FF8A1F ／ 淡 #FFC48A、7.5度ずつの帯を交互に）。全カット同じ（2026-11-07決定）
  - **左回りにゆっくり回し続ける**（1秒12度、1周30秒。カットをまたいで止めない）。ベンチマークは3チャンネルとも背景が動いている（①は左回りに1秒約13度）（2026-11-08）
  - 冒頭画面の写真（と矢印）は、カットのあいだに少しずつ大きくする（終わりで1.05倍）。タイトル枠と本編の写真は動かさない
  - ベンチマークは①水色、②ピンク、③ミントなので、かぶらないオレンジにした
- 文字と写真を置く範囲：y=97〜1552。上の0〜90と、下の1560〜1920は空ける（ショートの画面表示とかぶるため）。写真が縦に長くて下テロップが写真の下に出るときだけ y=1822 まで使う

## カット1：タイトル画面（サムネの代わり）
- タイトル枠：白地＋マゼンタ（濃いピンク）の太い枠、角丸。文字もマゼンタ、2〜3行、中央ぞろえ。y=200〜430くらい、横幅は画面いっぱい近く（x=30〜950）
- 写真は3パターン
  - A 縦に昔→今：昔 y=450〜980、今 y=980〜1580（強いモザイク）。境目の真ん中にマゼンタの下向き矢印
  - B 横に昔→今：左に昔、右にモザイクの今。境目に赤い右向き矢印
  - C 1枚まるごと：今の写真1枚に全体モザイク
- 長さ：冒頭の文を読み終わるまで（冒頭の文の字数÷7＋0.3秒以上。だいたい3〜4秒）
- 「今」の写真は、肩から上の顔アップに切り取ってからモザイクをかける。肌が広く出る衣装の写真は使わない
- モザイクは、誰か分からない強さにする。ただし髪の色・長さ・服の雰囲気の変化は伝わるように（ブロック約40〜60px）

## カット2以降：本編
- 上テロップ枠：y=97〜308（2行のとき）。白地＋黒い枠（約6px）＋角丸、中央ぞろえ。枠の横幅は文字の長さに合わせて伸び縮み（550〜880px）
- 写真：y=386〜1533、横幅は最大970px（x=55〜1024）、中央。縦長の写真は高さに合わせて、左右に背景が見えてもいい
- 下テロップ枠：写真の下の端に重ねる（y=1400〜1552くらい）。写真が縦に長いときは写真の下（y=1610〜1822）。2つ出すときは縦に重ねる
- 2枚比較：写真の範囲を上下に分けて、上＝昔、下＝今。上テロップで「上が10年前 下が今」
  - 縦長の写真（宣材写真など）は、左右に並べてもよい（左＝昔、右＝今。上テロップで「左が13歳 右が19歳」）。Remotion では compare に "layout": "side"
- 横長（16:9）のテレビのキャプチャは、写真枠を横長にして上下に背景を見せる

## 文字
- フォント：M PLUS Rounded 1c（無料・Google Fonts）。タイトルはBlack（900）、テロップはExtraBold（800）
- 大きさ：タイトル84px、テロップ78px。1つの枠に2行まで、1行11字まで
- タイトル枠：白地・マゼンタ（#E4007F）12px枠・角丸18px
  - 1行は10字まで（文字84pxで枠の中に入るのは約10字。半角の数字2つで全角1字くらい）。超えると折り返して4行になるので、行の分け方を変える
- テロップ枠：白地・黒（#141414）6px枠・角丸16px。横幅は文字に合わせる
- 色の使い分け
  - 日付・年齢・肩書き → 緑 #0B7A2E
  - ふつうの説明 → 青 #1A1AC8
  - 強調・数字・決めの一言 → 赤 #C8102E ／ 2色目にオレンジ #D9480F
  - ツッコミ・反応 → 紫 #7708AF（赤・青も可）
  - タイトル → マゼンタ #E4007F
- 出典ラベル：**画面には出さない**（2026-11-08 ユーザーが決定。ベンチマーク3チャンネルも画面には出していない）。出典は概要欄に写真ごとに書く。出す設定（spec の creditLabels: true）のときは、写真の左上に「出典：〇〇」（白文字28px・半透明の黒地・角丸8px）。公開より前のカットのラベルには答えが分かる名前を書かない
- 2枚比較のときは、各写真の左上に「10年前」「今」のラベル（白文字32px・黒地）

## カット割り
- 写真1枚＝1カット、1カット3.5〜4秒。公開カット（4〜5秒）と最後のカット（5〜6秒）だけ長め
- 1カットの中で「上テロップ → 下テロップ」を読み上げに合わせて出す。下テロップはカット開始の約2秒後
- 全体で6〜8カット
- 公開カットの今の写真は、昔の写真と同じくらいの大きさ・顔の位置にそろえる
- 締めで昔の写真をもう一度出して、今と見比べさせる形もある

## 音
- 声：VOICEVOX の青山龍星（2026-11-07決定）。テロップを全部そのまま読む（上→下の順）。概要欄に「VOICEVOX:青山龍星」のクレジットを入れる
- 効果音（すべて自作。scripts/se.py で作り、テンプレートが自動で鳴らす。2026-11-08）：冒頭の画面に「ドン」、テロップが出るたびに小さく「ポン」、公開の瞬間に「ジャン」（驚き）か「キラーン」（明るい・うれしい場面）。カットの切り替えの「シュッ」は使える形で用意してあるが、既定では鳴らさない
- BGM：入れていない（ベンチマークでは未確認）

## ②③との違い（参考）
- ②：テロップは1枠3行で大きめ（上 y≈125〜550、下 y≈1400〜1880）。約30%地点にマスコットの区切りカード「ほな、イクで！」。新チャンネルでは区切りカードもマスコットも使わない（2026-11-07決定）
- ③：小さめの枠を前の枠に重ねて積んでいく（2ちゃんねるのレスが増えていく見せ方）。テロップに絵文字を使う

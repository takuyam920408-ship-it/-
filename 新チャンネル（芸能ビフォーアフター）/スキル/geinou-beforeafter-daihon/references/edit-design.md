# 編集デザインの型

座標は 1080×1920 の画面での位置（x＝左から、y＝上から、単位px）。ベンチマーク①こっそり速報の画面を測った値が基本で、②③との違いは最後にまとめた。

## 画面全体
- サイズ：1080×1920（縦）
- 背景：1色の放射線（集中線）。濃淡2色の帯を交互に並べる。全カット同じ
  - ①は水色（#25D0FE 前後と #87DFF7 前後）、②はピンク、③はミント
  - 新チャンネルは、この3色とかぶらない色（黄色・オレンジ・紫など）にする。チャンネル色が未定なら【要確認】に書く
- 文字と写真を置く範囲：y=97〜1552。上の0〜90と、下の1560〜1920は空ける（ショートの画面表示とかぶるため）。写真が縦に長くて下テロップが写真の下に出るときだけ y=1822 まで使う

## カット1：タイトル画面（サムネの代わり）
- タイトル枠：白地＋マゼンタ（濃いピンク）の太い枠、角丸。文字もマゼンタ、2〜3行、中央ぞろえ。y=200〜430くらい、横幅は画面いっぱい近く（x=30〜950）
- 写真は3パターン
  - A 縦に昔→今：昔 y=450〜980、今 y=980〜1580（強いモザイク）。境目の真ん中にマゼンタの下向き矢印
  - B 横に昔→今：左に昔、右にモザイクの今。境目に赤い右向き矢印
  - C 1枚まるごと：今の写真1枚に全体モザイク
- 長さ：冒頭の文を読み終わるまで（約3秒）
- モザイクは、誰か分からない強さにする。ただし髪の色・長さ・服の雰囲気の変化は伝わるように（ブロック約40〜60px）

## カット2以降：本編
- 上テロップ枠：y=97〜308（2行のとき）。白地＋黒い枠（約6px）＋角丸、中央ぞろえ。枠の横幅は文字の長さに合わせて伸び縮み（550〜880px）
- 写真：y=386〜1533、横幅は最大970px（x=55〜1024）、中央。縦長の写真は高さに合わせて、左右に背景が見えてもいい
- 下テロップ枠：写真の下の端に重ねる（y=1400〜1552くらい）。写真が縦に長いときは写真の下（y=1610〜1822）。2つ出すときは縦に重ねる
- 2枚比較：写真の範囲を上下に分けて、上＝昔、下＝今。上テロップで「上が10年前 下が今」
- 横長（16:9）のテレビのキャプチャは、写真枠を横長にして上下に背景を見せる

## 文字
- フォント：極太のゴシック（例：Noto Sans JP Black、源ノ角ゴシック Heavy）
- 大きさ：75〜85px。1つの枠に2行まで、1行11字まで
- 色の使い分け（①で見られたもの）
  - 日付・年齢・肩書き → 緑
  - ふつうの説明 → 青（#1A1AC8 前後）
  - 強調・数字・決めの一言 → 赤（#B80607 前後）／オレンジ
  - ツッコミ・反応 → 紫（#7708AF 前後）／赤／青
  - タイトル → マゼンタ

## カット割り
- 写真1枚＝1カット、1カット3.5〜4秒。公開カット（4〜5秒）と最後のカット（5〜6秒）だけ長め
- 1カットの中で「上テロップ → 下テロップ」を読み上げに合わせて出す。下テロップはカット開始の約2秒後
- 全体で6〜8カット
- 公開カットの今の写真は、昔の写真と同じくらいの大きさ・顔の位置にそろえる
- 締めで昔の写真をもう一度出して、今と見比べさせる形もある

## 音
- 声：1人の読み上げ。テロップを全部そのまま読む（上→下の順）。関西弁のイントネーションが自然に出る声を選ぶ
- BGM・効果音：ベンチマークでは未確認。入れるなら、公開の瞬間に驚き系のSEを1つ、くらいに絞る

## ②③との違い（参考）
- ②：テロップは1枠3行で大きめ（上 y≈125〜550、下 y≈1400〜1880）。約30%地点にマスコットの区切りカード「ほな、イクで！」。新チャンネルでも、自分のマスコットか決めゼリフのカードを作ると覚えてもらいやすい
- ③：小さめの枠を前の枠に重ねて積んでいく（2ちゃんねるのレスが増えていく見せ方）。テロップに絵文字を使う

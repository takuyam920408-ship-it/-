# 審査担当への依頼文

SKILL.md 9章の審査で、4人の審査担当に渡す依頼文。`{...}` の部分を埋めて使う。
4人には同じ材料（2つの台本ファイル、確認済みの出典URLの一覧、このスキルのSKILL.mdの場所）を渡し、**別々に、同時に**審査させる。ポリシー担当には、policy.md の場所も渡す。

---

## 共通の前置き（4人とも最初に付ける）

```
YouTubeショートのチャンネル「答え合わせ速報」の台本を審査してください。
女性芸能人・アイドル・インフルエンサーの「昔→今」などのギャップを、冒頭で答えを隠して、動画の中で答え合わせする作りです。

- 台本（プレーン版）：{プレーン版のパス}
- 台本（カット割り版）：{カット割り版のパス}
- 型のルール：{SKILL.mdのパス}（必要な章だけ読めばよい）
- 確認済みの出典：
{出典URLと、それで確認した事実の一覧}

あなたの担当は下の観点だけです。ほかの観点の問題に気づいても、指摘は担当の範囲に絞ってください。
ファイルは読むだけで、書き換えないでください。

答え方：
- 問題がなければ「問題なし」とだけ書く
- 問題があれば、1つずつ次の形で書く
  ・どこ：（カット番号、または【YouTubeタイトル】【概要欄】など）
  ・何が問題か：
  ・直し方：（差し替える文まで書く）
  ・根拠：（SKILL.mdの章、または出典）
- 「直した方がいい」と「好みの問題」は分けて書く。好みの問題は、指摘の最後に「好み」とまとめる
```

## 伸ばす担当

```
担当：最後まで見られて、コメントが付く台本になっているか。

確認すること：
1. 冒頭の文：2秒で「誰の・何のギャップか」が分かるか。答え（今の姿・結果）を言っていないか。判定ワードか問いかけが入っているか（SKILL.md 4-4）
2. 公開の位置：型Aなら13〜16秒、型Bなら7〜12秒、型Cなら10〜13秒あたりか。公開の前に、昔を褒めて溜めを作れているか（4-2）
3. 公開カット：ツッコミが2つ積まれていて、驚きが一番大きくなっているか（4-3）
4. 締め：最後の一言が冒頭の文を、言葉と意味の両方で回収しているか。寂しく終わっていないか（4-5）
5. コメント：反対の意見が1回入っていて、「どっち派」で割れる余地があるか。「昔も好き」のような「も」で同意になっていないか（4-6）
6. YouTubeタイトル：誰＋ギャップ＋判定ワード＋「ｗ」か「…」になっているか。名前を出すかどうかの判断は合っているか（5章）
7. 冒頭画面：今の写真が、モザイク越しでも昔との差が分かる写真になっているか（6章）
8. テンポ：説明だけの行が2行以上続いて、だれていないか。1行に日付・名前・数字を詰め込んでいないか（4-6）
9. 締めが「コメントで教えて」のような直接のお願いになっていないか（4-6）
10. 台本メモ.txt があれば、直近10本と冒頭の文・締め・公開の一言がかぶっていないか（4-8）
```

## 信頼担当

```
担当：事実が正しいか。

確認すること：
1. 台本・タイトル・概要欄・タグに出てくる事実（年齢・日付・期間・数字・順位・経歴・本人の発言）を1つずつ、確認済みの出典と照らし合わせる。出典で確認できないものは、すべて指摘する（SKILL.md 3章）
   - 上の一覧で足りなければ、自分で検索して確かめてよい。そのときは見つけた出典URLも書く
   - 年齢は、生年月日と日付から計算が合っているかも確かめる。「〇歳で〜」は、その出来事の日付で計算する
2. 表示回数・いいね数・順位が、出典の数字より大きくなっていないか（丸めるのは「約」「以上」まで）。出典によって数字が食い違うものを断定していないか
3. 伝聞の口調（〜らしい、〜って声）で、確認していないことをごまかしていないか。「〜って声」は、実際にその声が出典にあるか
4. 本人の発言として書いた文が、元の発言と食い違っていないか（言い換えで意味を足していないか）
5. 「速報」「今」「最新」と言っているものが、本当に最近のことか（出典の日付）
6. 出典がまとめサイト・無断転載アカウントになっていないか。元の投稿・元の記事か
7. 概要欄の出典リストに、台本で使った事実と写真の出典が全部あるか。概要欄の事実の文が、台本と食い違っていないか
```

## 構成担当

```
担当：型どおりの形になっているか。

確認すること：
1. 起承転結の順番と秒数が、選んだ型（A・B・C）に合っているか（SKILL.md 4-1、4-2）
2. 1カット＝写真1枚＝上テロップ1つ＋下テロップ1つか。下テロップが2つなのは公開カットだけか（4-3）
3. 1つのテロップは6〜15字、画面では1行11字までで折り返して2行までか。字数はスペースを数えず、半角の英数字は2字で全角1字と数える（4-3）
4. テロップの合計が180〜210字、合計が25〜33秒に入っているか。カットごとの秒数を足して合計と合うか。カット1は冒頭の文の字数÷7＋0.3秒以上あるか
5. 正体（グループ名・今の肩書き）は公開の後か。今の方が有名な人なら、名前も公開の後か。公開より前のカットの写真（冒頭画面も含む）に、答えが分かる名前の文字（テロップ・名札・ボード）が写る指示になっていないか（4-6、6章）
5-2. 2枚比較のカットに、「上が〇年前 下が今」の上テロップか、「昔」「今」のラベルがあるか（4-3）
6. 昔の写真は毎カット別の写真か（4-3）
7. プレーン版とカット割り版で、テロップの文が一字一句同じか
8. カット割り版：画面の共通設定（オレンジの背景・枠・フォント）、冒頭画面のパターン、写真リスト（出典URLか検索キーワード）、【要確認】がそろっているか（7章）
9. プレーン版：【型】【冒頭の文】【YouTubeタイトル】【Xの一言】【台本】【サムネ】【タグ】【ハッシュタグ】【概要欄】【要確認】がそろっているか。概要欄に出典リストと、声・BGMのクレジット欄があるか（7章）
10. 写真リストの写真が全部どこかのカットで使われているか。カットで使う写真が全部写真リストにあるか
```

## ポリシー担当

```
担当：YouTubeのポリシー・収益化の条件と、権利・法律に触れないか。
ルールは {policy.mdのパス} にある。全部読んでから審査する。
ほかの担当の意見より優先される担当なので、「伸びるから」という理由で見逃さない。迷うものは「要確認」として指摘する。

確認すること：
1. 題材（policy.md 1章）
   - 主役は今18歳以上か（生年月日で確かめる）
   - 主役が一般人ではないか。一般人なら、本人が名前・顔を出して発信していて、すでに広く話題になっているか
   - 病気・妊娠・交際・結婚・離婚・事件・逮捕・訃報・体重・整形に触れていないか。触れているなら、本人や事務所が公表した範囲だけで、ネタにしていないか
   - 噂・ゴシップを事実として扱っていないか
   - 整形の噂がよく語られている人の場合、「韓国行ったら」「誰やねん」「別人すぎやろ」などの並びで、整形をほのめかしているように読まれないか（読まれるなら「雰囲気変わりすぎやろ」などに替える案を出す）
2. 表現（policy.md 2章、SKILL.md 4-7）
   - 容姿をけなす言葉、昔の姿をけなす言葉がないか
   - ほかの実在の人と比べてけなす表現がないか
   - 性的な表現（体の部位、性的な目線、伏せ字の下ネタ、「エッッ」などのスラング）がないか
   - 国籍・人種・出身地などで決めつける言葉がないか
   - からかい・いじめに見える構成（1人を繰り返し笑いものにする、悩みをネタにする）になっていないか
   - 「悲報」型なら、最後に褒めで回収しているか。事件・不祥事が本当に起きたように受け取られないか
   - 名誉毀損・侮辱・プライバシー侵害に当たりそうな文がないか（policy.md 7章）
3. 写真・素材（policy.md 3章、カット割り版の写真リスト）
   - 写真の出どころの優先順位（本人のSNS→公式→報道写真）を守っているか。報道写真が多すぎないか
   - まとめサイト・無断転載の画像を使っていないか
   - 引用の形（自分の解説が主役・枠で区別・出典を概要欄に写真ごとに書く・必要な写真だけ・4〜8枚）になっているか（画面の出典ラベルは出さない運用）
   - 写真の中身を加工する指示（美肌・輪郭・色味）がないか
   - モザイクが、裸や下着を連想させる使い方になっていないか。冒頭のモザイク用の写真は、肩から上の顔アップに切り取る指示があり、肌が広く出る衣装の写真を避けているか
   - 概要欄の出典が、写真ごとに実際の投稿・記事のURLになっているか（アカウントのトップページだけになっていないか）
   - 写真は、スクショも含めて8枚以内か
   - 主役以外の一般人の顔をぼかす・切り取る指示があるか（写っている写真の場合）
   - 未成年の頃の写真が、公式写真・衣装・テレビのキャプチャに限られているか。水着・グラビア・露出の多い写真がないか。18歳になる前か後かを、誕生日の日付まで見て判断しているか
   - テレビの映像を長く流す指示になっていないか
   - AIで作った画像や声を、実在の人のものとして使っていないか
4. タイトル・サムネ・タグ（policy.md 4章）
   - タイトル・冒頭画面で言ったことを、動画の中で答え合わせしているか（中身と一致しているか）
   - タイトル・冒頭画面に性的な連想をさせる言葉や画像がないか
   - タグ・ハッシュタグに、中身と関係ない名前や話題が入っていないか。ハッシュタグは3〜5個か
5. 声・音楽（policy.md 5章）
   - 概要欄に、読み上げの声とBGMのクレジット欄があるか
6. 収益化（policy.md 6章、SKILL.md 4-8）
   - 各カットに自分の解説かツッコミがあり、写真を並べるだけになっていないか
   - 台本メモ.txt があれば、直近10本と冒頭の文・締め・公開の一言がかぶっていないか
   - 広告が付きにくい内容（性的・汚い言葉・ショッキング・事件や悲劇のネタ化）がないか
```

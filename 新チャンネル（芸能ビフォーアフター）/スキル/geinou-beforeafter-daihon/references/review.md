# 審査担当への依頼文

SKILL.md 9章の審査で、3人の審査担当に渡す依頼文。`{...}` の部分を埋めて使う。
3人には同じ材料（2つの台本ファイル、確認済みの出典URLの一覧、このスキルのSKILL.mdの場所）を渡し、**別々に、同時に**審査させる。

---

## 共通の前置き（3人とも最初に付ける）

```
YouTubeショートのチャンネル「答え合わせ速報」の台本を審査してください。
女性芸能人・アイドル・インフルエンサーの「昔→今」などのギャップを、冒頭で答えを隠して、動画の中で答え合わせする作りです。

- 台本（プレーン版）：{プレーン版のパス}
- 台本（カット割り版）：{カット割り版のパス}
- 型のルール：{SKILL.mdのパス}（必要な章だけ読めばよい）
- 確認済みの出典：
{出典URLと、それで確認した事実の一覧}

あなたの担当は下の観点だけです。ほかの観点の問題に気づいても、指摘は担当の範囲に絞ってください。
ファイルは読むだけで、書き換えないでください。

答え方：
- 問題がなければ「問題なし」とだけ書く
- 問題があれば、1つずつ次の形で書く
  ・どこ：（カット番号、または【YouTubeタイトル】【概要欄】など）
  ・何が問題か：
  ・直し方：（差し替える文まで書く）
  ・根拠：（SKILL.mdの章、または出典）
- 「直した方がいい」と「好みの問題」は分けて書く。好みの問題は、指摘の最後に「好み」とまとめる
```

---

## 伸ばす担当

```
担当：最後まで見られて、コメントが付く台本になっているか。

確認すること：
1. 冒頭の文：2秒で「誰の・何のギャップか」が分かるか。答え（今の姿・結果）を言っていないか。判定ワードか問いかけが入っているか（SKILL.md 4-4）
2. 公開の位置：型Aなら13〜16秒、型Bなら7〜12秒、型Cなら10〜13秒あたりか。公開の前に、昔を褒めて溜めを作れているか（4-2）
3. 公開カット：ツッコミが2つ積まれていて、驚きが一番大きくなっているか（4-3）
4. 締め：最後の一言が冒頭の文を、言葉と意味の両方で回収しているか。寂しく終わっていないか（4-5）
5. コメント：反対の意見が1回入っていて、「どっち派」で割れる余地があるか（4-6）
6. YouTubeタイトル：誰＋ギャップ＋判定ワード＋「ｗ」か「…」になっているか。名前を出すかどうかの判断は合っているか（5章）
7. 冒頭画面：今の写真が、モザイク越しでも昔との差が分かる写真になっているか（6章）
8. テンポ：説明だけの行が2行以上続いて、だれていないか
```

## 信頼担当

```
担当：事実と表現に問題がないか。

確認すること：
1. 台本・タイトル・概要欄に出てくる事実（年齢・日付・期間・数字・経歴・本人の発言）を1つずつ、確認済みの出典と照らし合わせる。出典で確認できないものは、すべて指摘する（SKILL.md 3章）
   - 上の一覧で足りなければ、自分で検索して確かめてよい。そのときは見つけた出典URLも書く
   - 年齢は、生年月日と日付から計算が合っているかも確かめる
2. 表示回数・いいね数が、出典の数字より大きくなっていないか（丸めるのは「約」「以上」まで）
3. 伝聞の口調（〜らしい、〜って声）で、確認していないことをごまかしていないか
4. SKILL.md 4-7の「入れないもの」がないか
   - 体を性的にいじる表現、伏せ字の下ネタ
   - ほかの実在の人と比べてけなす表現
   - 整形などの断定
   - 容姿をけなしたまま終わる構成
5. 昔の写真や前の姿をけなす言葉がないか
6. 未成年の時期の写真を使う場合、写真リストで衣装・公式写真などに限っているか
7. 概要欄の出典リストに、台本で使った事実と写真の出典が全部あるか
```

## 構成担当

```
担当：型どおりの形になっているか。

確認すること：
1. 起承転結の順番と秒数が、選んだ型（A・B・C）に合っているか（SKILL.md 4-1、4-2）
2. 1カット＝写真1枚＝上テロップ1つ＋下テロップ1つか。下テロップが2つなのは公開カットだけか（4-3）
3. 1行6〜15字、1つの枠は2行まで（1行11字を超えたら改行）か
4. テロップの合計が180〜210字、合計が25〜33秒に入っているか。カットごとの秒数を足して合計と合うか
5. 正体（グループ名・今の肩書き）は公開の後か。今の方が有名な人なら、名前も公開の後か（4-6）
6. 昔の写真は毎カット別の写真か（4-3）
7. プレーン版とカット割り版で、テロップの文が一字一句同じか
8. カット割り版：画面の共通設定（オレンジの背景・枠・フォント）、冒頭画面のパターン、写真リスト（出典URLか検索キーワード）、【要確認】がそろっているか（7章）
9. プレーン版：【型】【冒頭の文】【YouTubeタイトル】【Xの一言】【台本】【サムネ】【タグ】【ハッシュタグ】【概要欄】【要確認】がそろっているか（7章）
```

# 芸能ビフォーアフター台本

## このスキルについて

ユーザーの新チャンネル（チャンネル名は未定）向けのショート台本を作る。題材は女性芸能人・アイドル・インフルエンサーの「昔→今」のギャップ。
型は、伸びているベンチマーク3チャンネル（①こっそり速報 ②オトナの夜ふかしch ③男子の味方ch）を2026年11月に分析して作った。数字の根拠や実例は `references/benchmark-data.md` にある。

納品するのは毎回2ファイル（7章）。
- **プレーン版**：タイトル・台本・概要欄など、そのまま使う文字だけ
- **カット割り版**：カットごとの写真・テロップ・秒数。編集の設計図

写真や動画の素材は自動で集めない（著作権や各サービスの規約があるため。ユーザーのほかのスキルと同じ方針）。カットごとに「どんな写真か」と「出典URLか検索キーワード」を書くだけにして、集めるのはユーザー本人に任せる。

---

## 1. 作業の流れ

1. **題材を決める**（2章）：ユーザーが人物を指定していればそれを使う。指定がなければ候補を3つ出して選んでもらう
2. **事実を集めて裏を取る**（3章）
3. **型を選び、写真の役割を決める**（4章・6章）
4. **台本を書く**（4章）
5. **YouTubeタイトル・概要欄・タグを書く**（5章・7章）
6. **セルフチェック**（8章）
7. **2ファイルを保存して渡す**（7章）

ユーザーが台本のレビューや手直しを頼んできた場合は、8章のチェックリストと4章の型に照らして、直すところと理由を示してから直す。

---

## 2. 題材の選び方

伸びる題材の条件（ベンチマークの上位動画に共通）：

- **主役は1人、ギャップは1つ**。昔↔今、加工↔無加工、ON↔OFF、日本時代↔韓国デビュー後、など。3選・まとめは伸びない（ベンチマーク①の3選は3千〜7千回）
- **知名度は「名前は知らなくても、見たら驚く」くらいがいちばん強い**。全体1位（579万回）は日本では知られていない「田中杏奈」が韓国でデビューした話で、公開で本当に驚けた。同じ型でも、すでに有名なNiziUのミイヒさんの回は40万回だった（答えを知っている人が多い）
- 誰でも知っている人を使うなら、「1年半ぶりの公の場」「ママになった今」のように**今の新しい情報**がある時にする（永野芽郁の回314万回）
- **今話題になっている**：映画祭の登壇、結婚、実写化キャスト発表、本人の比較投稿が数百万回表示された、など
- **写真が手に入る**：本人のSNS、公式写真、報道写真

避ける題材：
- 一般人（本人が公開で発信していて、すでに話題になっている場合を除く）
- 未成年を容姿でいじる切り口
- 病気・事件・離婚などをネタとして笑う切り口
- 続編（「前に出した〜のその後」は2,939回）

ネタ候補を出すときは、候補ごとに「誰か／どんなギャップか／なぜ今か（話題の根拠と出典）／手に入りそうな写真」を1〜2行で書き、おすすめを1つ示す。

---

## 3. ファクトチェック

実在の人を扱うので、台本に入れる事実（年齢・日付・期間・数字・経歴・本人の発言）は、一次情報（本人のSNS投稿、公式発表、報道）で確認できたものだけにする。

- 表示回数・いいね数は、実際の投稿で確認した数字を使う。「約〜」「〜以上」で丸めてよい
- 確認できないことは台本に入れない。どうしても入れたいときは【要確認】に回して、ユーザーに判断してもらう
- 「〜らしい」「〜って声」は口調として使うが、確認していないことを書くための逃げ道にはしない
- 出典URLは控えておき、概要欄の出典リストに全部載せる（ベンチマーク①がこの形）

## 4. 台本の型

### 4-1. 型を選ぶ

| 型 | 使う題材 | 公開のタイミング |
|---|---|---|
| **A 昔→今**（メイン） | 垢抜け・成長・ブランク明け・韓国デビュー | 真ん中（13〜16秒） |
| **B 比較・逆転** | 加工↔無加工、ON↔OFF、すっぴん↔メイク、2枚の写真 | 早め（7〜12秒）。そのあと比較を1〜2組おかわり |
| **C 話題・ニュース** | 実写化キャスト、新センター、新司会、結婚 | 10〜13秒（「〇〇やる子がこいつや」） |

迷ったらA。

### 4-2. 起承転結（型A・30秒の場合）

| | 秒 | やること | テロップの例 |
|---|---|---|---|
| **起** | 0〜3 | タイトル画面。冒頭の文を読む。今の顔はモザイクで隠す | 元から可愛いのに韓国行ったらこうなるｗ |
| **承** | 3〜13 | 昔の写真を2〜3枚替えながら、いつ・何歳・何者かを言う。**昔もちゃんと褒める** | 2016年 20歳の〇〇／この時点で十分可愛いやろ／もう完成しとるやん |
| **転** | 13〜18 | 公開。今の写真を出して、短いツッコミを2つ積む | そんで今がこれや／誰やねん／別人すぎやろ |
| **結①** | 18〜26 | 裏付け・おまけ。正体（グループ名・今の肩書き）、数字、本人の言葉 | 比較の投稿が537万表示／全部本人が言うてる |
| **結②** | 26〜30 | 締め。**冒頭の文を回収する一言**（4-5） | 元から可愛かったのにな |

公開を真ん中に置くのは、前半で「昔も可愛い」と納得させてから驚かせると、驚きが大きくなるから。冒頭で答えを隠しているので、見る人は公開まで離れにくい。

型B・Cも「起で答えを隠す → 前フリ → 公開 → ツッコミ → 裏付け → 回収の締め」の順番は同じ。
③男子の味方chの1位のように、冒頭でモザイクにした写真を**最後に外して**ひっくり返す形（「そろそろ限界か…」→「大人の色気増してきたやろ」）もある。悲報っぽいタイトルのときに使える。

### 4-3. カットの作り方

- **1カット＝写真1枚＝上テロップ1つ＋下テロップ1つ**。上を読み終えてから下を出す（カットが始まって約2秒後）
- **公開カットだけ下テロップを2つ**にする（「誰やねん」→「別人すぎやろ」）。一番驚かせたいところでツッコミを増やす
- 1カットは3.5〜4秒。公開カット（4〜5秒）と最後のカット（5〜6秒）だけ長めにする
- 全体で6〜8カット、14〜16行、合計180〜210字、25〜33秒（読み上げは1秒に約7字）
- 1行は6〜15字。1つの枠は2行まで（1行11字を超えたら途中で改行）
- 昔の写真は**毎カット別の写真**にする。使い回すと「昔も可愛い」の説得力が落ちる（579万回の動画は昔の写真4枚がすべて別、40万回の動画は2枚）

### 4-4. 冒頭の文（起）の5つの型

冒頭の文は、1カット目のタイトル枠に出して最初に読む文。YouTubeタイトルと同じでもいいし、別にしてもいい（5章）。

1. **ギャップ宣言型**：何がどう変わったかを言い切る。答えは見せない
   例「元から可愛いのに韓国行ったらこうなるｗ」（579万）「〇〇 1年半ぶりの姿がこれらしい」（314万）
2. **判定ツッコミ型**：隠した答えへの感想を先に言う
   例「垢ぬけるにもほどがあるやろwww」（220万）「面影なさすぎやろwww」（140万）
3. **問いかけ型**：見た人に答えさせる
   例「どうやってここから最強ビジュアル手に入れたん？」（150万）
4. **悲報→実は褒め型**：悪いニュースっぽく見せて、中身は褒めで回収する
   例「【悲報】〇〇さん(34) そろそろ限界か…」（140万）
5. **有名人の関係型**：有名な家族・恋人・共演者との関係を使う
   例「さすが〇〇を自宅に入れた漢…」（410万）

冒頭の文のチェック：
- 2秒で「誰の・何のギャップか」が分かる
- 答え（今の顔・結果）は言わない、見せない
- 判定ワード（ヤバい・別人・限界・反則・レベチ）か、問いかけが入っている
- 3行以内。文末に「ｗ」「…」「？」のどれかがある

伸びなかった冒頭の文は、ギャップも問いもない感想だけ（「こういうお嫁さんと新婚生活送りたかった」）、主役が無名か複数（「〇〇のそっくりさん大量に見つかる」）、何の話か一瞬で分からない、のどれかだった。

### 4-5. 最後の一言で冒頭の文を回収する（いちばん大事）

3チャンネルの1位動画は、3本とも**最後の一言が冒頭の文を回収して**終わっている。見終わったときに「そういうことか」とスッキリして、もう一度見たくなり、コメントも書きたくなる。

- 言葉を合わせる：「元から可愛い**のに**韓国行ったらこうなるｗ」→「元から可愛かった**のにな**」
- 答え合わせ：「さすが有村架純を自宅に入れた漢…」→「そもそもこの人 自宅に有村架純呼んでるからな」
- ひっくり返す：「そろそろ限界か…」→「なんでや大人の色気増してきたやろ」

締めを書いたら、冒頭の文と並べて読み、つながっているかを必ず確かめる。

### 4-6. テロップの口調

テロップは「説明」ではなく**見ている人の心の声**。全部を1人の声が読み上げる（画面の文＝ナレーション）。

- 関西弁＋伝聞：〜やろ／〜やん／〜しとる／〜やって／〜らしい／〜しもた。一人称は「ワイ」
- **昔をけなさない**：「この時点で十分可愛いやろ」と一度褒めてから今で驚かせる。昔を落とすと、ファンのコメントが荒れる
- **反対の意見を1回入れる**：「いや〜」と反論するテロップや、「ワイは昔の方が好きやわ」を入れると、コメント欄が「どっち派」で盛り上がる
- **正体（グループ名・今の肩書き）は公開の後に出す**。先に出すと、知っている人には答えが分かってしまう（40万回の動画は名前を5秒で出していた）
- **数字を2回以上入れる**：年・年齢・期間・表示回数・いいね数
- 読点（、）はなるべく使わず、改行で区切る

よく使う言い回し：
- 導入：この子が2ヶ月前や／日本のオーディションに出とった人や／〇年前の〇〇
- 昔を褒める：この時点で十分可愛いやろ／もう完成しとるやん／普通に可愛いやん／この頃はまだ素朴な感じやった
- 溜め：ここから韓国に渡るんやけど／ここから約1年半 表に出ず／ずっとこの路線やったらしい
- 公開：そんで今がこれや／〇〇行った結果がこれ／〇年ぶりの今がこれ／なお現在がこちら
- 驚き：誰やねん／同じ人なんか／別人すぎやろ／嘘やろ／同一人物とは思えんやろ
- 裏付け：比較の投稿が〇〇万表示／全部本人が言うてる／公式の写真がこれ／〜って声も
- 締め：〇歳でこの顔は反則やろ／〇ヶ月でここまで来るか／努力でここまで変わるんやな／ワイは昔の方が好きやわ

### 4-7. 入れないもの

ベンチマーク②③にはあるが、新チャンネルには入れない。

- **体を性的にいじるテロップや、伏せ字の下ネタ**：実在の人を性的にいじる内容は、YouTubeのハラスメント・性的コンテンツのポリシーに触れやすく、年齢制限や収益化の停止、削除のリスクが高い。本人や事務所とのトラブルにもなりやすい
- **ほかの実在の人と比べてけなす表現**（「〇〇みたいになってる」など）
- **整形などの断定**
- **容姿をけなしたまま終わる構成**：悲報っぽく始めても、最後は褒めで回収する

## 5. YouTubeタイトル

形：**誰（名前か肩書き）＋ギャップ＋判定ワード＋「ｗ」か「…」**。15〜30字。

- 誰でも知っている名前は出す（「永野芽郁 1年半ぶりの姿がこれらしい」314万）
- 知名度が中くらいの人は肩書きで隠す（「元から可愛いのに韓国行ったらこうなるｗ」579万）
- 強い言葉：「今こうなってる／今がこれ／こうなる」（ベンチマーク①で、これを含むタイトルの再生の中央値は14.7万、含まないタイトルは2.6万）、【悲報】やネガティブな言葉で始めて中身は褒める（②で64.2万対11.8万、③で16.5万対8.3万）、文末の「…」
- 弱い言葉：「発見」「見つかる」「判明」（②で2.3万対13.9万）、3選、主役が複数

冒頭の文との関係：
- 同じにする（①③の形）：いちばん簡単で、ズレがない
- 分ける（②の形）：タイトルで「〜の理由ヤバいやろw」と問いを立て、冒頭の文でその答えを謎めいた形で先に出す

## 6. 写真の選び方

1本で4〜8枚。役割で選ぶ。

| 役割 | 使う場所 | 選び方 |
|---|---|---|
| フック用の2枚 | 1カット目 | 昔と今の差が一番大きい組み合わせ。今の方はモザイクで隠す |
| 昔の写真 2〜3枚 | 承 | 「素朴」「普通」が伝わるもの。卒アル、オーディションのプロフィール、デビュー当時、昔のテレビのキャプチャ。毎カット別の写真 |
| 今の写真 1〜2枚 | 転 | 最新で一番きれいに写っているもの。公式写真、イベント登壇、本人のSNS |
| 裏付け 1〜2枚 | 結① | SNS投稿のスクショ（表示回数・いいね数が見える）、名前のテロップ入りのテレビのキャプチャ、公式の発表 |
| 締め 1枚 | 結② | 昔の写真をもう一度、か、今の別カット |

見た目の基準：
- **モザイク越しでも差が分かる組み合わせ**にする。髪の色・長さ、服の雰囲気、明るさが変わっているもの。579万回の動画は「黒髪の前髪あり」→「茶色のロングヘア・赤い口紅」で、モザイク越しでも変化が見えた。40万回の動画は昔も今も黒髪で、差が分かりにくかった
- 顔が大きく、正面か斜め前を向いている。後ろ姿・遠景は避ける
- 昔と今は、顔の大きさ・向き・切り取り方をそろえる
- 明るい写真を選ぶ。暗い・ぶれている写真は避ける
- テレビのキャプチャは、名前のテロップが入っているものが強い（「誰か」の証拠になる）
- 本人が公開した写真・公式写真を中心にして、出典は概要欄に全部書く

## 7. 納品形式

毎回2ファイルを `.txt` で保存する（`.md` だと単一の改行が詰まって表示が崩れるため）。ファイル名は対応が分かるように揃える。

- `〇〇_台本.txt`（プレーン版）
- `〇〇_台本_編集カット割り.txt`（カット割り版）

保存場所は、プロジェクトフォルダに「新チャンネル（芸能ビフォーアフター）」フォルダがあればその中、なければ作業フォルダ。

```
写真1：（何の写真か）／出典URL（なければ検索キーワード）
写真2：
…

【要確認】
1.
```

- 秒数は、そのカットのテロップの文字数から出す（1秒に約7字＋間）。合計が25〜33秒に入るように調整する
- ナレーション・BGM/SEは、意味があるカットにだけ書く（公開の瞬間、締めの一言など）。全カットに書くと大事な切り替えどころが埋もれる
- 画面の細かい座標・色は `references/edit-design.md` を見る

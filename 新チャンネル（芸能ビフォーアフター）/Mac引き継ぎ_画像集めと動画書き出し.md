## 1. 画像スキル（hannoushuu-gazou の答え合わせ速報版）

名前の案：`kotaeawase-gazou`。入力はカット割り版の【写真リスト】。

**集め方（自動）**
- 写真リストの各写真を、元の投稿・元の記事までたどって取得する。優先順位は ①本人がSNSで公開した写真 ②事務所・番組・作品の公式写真 ③報道写真（代わりがないときだけ）
- Xの写真は、反応集と同じく埋め込み用の公開の仕組み（`cdn.syndication.twimg.com/tweet-result`）で、画像とハンドルを status ID から取る
- 報道記事は、記事ページの画像（og:image など）を取る
- **ログインが必要なところ（Instagram など）は自動で取らない**。写真番号と投稿URLを一覧にして、ユーザーに保存を頼む
- まとめサイト・Pinterest・ファンの転載アカウントの画像は使わない
- フォルダは反応集にそろえる：`~/youtube-editing/kotaeawase/<id>/raw`（元画像）・`stage`（切り取り後）・`pick`（採用）
- `画像の出どころ.json` に、写真番号・何の写真か・元のページのURL・画像のURL・投稿者（Xは status ID とハンドル）・投稿日・取得日時を残す

**素材チェック担当（原寸で見る）**
反応集の「原寸で見る」ルールをそのまま使い、次も確かめる。
- 公開より前のカット（冒頭画面を含む）の写真に、答えが分かる名前の文字（テロップ・名札・ボード）が写っていないか
- 冒頭のモザイク用の「今」の写真は、肩から上の顔アップに切り取れるか。肩・胸元・お腹の肌が広く出る衣装ではないか
- 主役以外の一般人（観客・ファン・家族）の顔が写っていたら、切り取るかぼかす
- 18歳になる前の写真か後かを、誕生日の日付まで見て判断する。未成年の頃の写真は公式写真・衣装・テレビのキャプチャだけ。水着・グラビア・露出の多い写真は使わない
- 冒頭の昔と今は、モザイク越しでも差（髪の色・長さ・服・雰囲気）が見えるか
- 顔が大きく、明るく、ブレていないか。昔と今で顔の大きさ・向きをそろえられるか
- 写真の中身は加工しない（美肌・輪郭・色味はいじらない。明るさの軽い調整・切り取り・冒頭のモザイクだけ）
- 1本4〜8枚（スクショも含む）。ほかの回と同じ写真を使っていないか（sim_images.py と同じ確認）

## 2. 動画（Remotion）

**テンプレートはクラウド側で作成済み**（2026-11-08）：リポジトリの `新チャンネル（芸能ビフォーアフター）/remotion-kotaeawase/`。`specs/<id>.json` を書いて `node scripts/render.mjs <id>` で書き出す。使い方と spec の書き方は同じフォルダの README.md。見本（`specs/mihon.json`、グレーの仮画像、7カット・28.3秒）はユーザーに確認してもらう。
Macでは、このフォルダを使って、画像（public/<id>/）と VOICEVOX の音声（voice）を入れて書き出す。Macの `~/youtube-editing/remotion-kotaeawase/` に以前作りかけたものがあれば、こちらにそろえる。
以下は画面の決まり（テンプレートに入っている値）。

**画面**（くわしくは edit-design.md）
- 1080×1920、30fps
- 背景：オレンジの放射線（濃 #FF8A1F ／ 淡 #FFC48A、7.5度ずつの帯を交互に）。左回りにゆっくり回し続ける（1秒12度。テンプレートに入っている）。冒頭画面の写真は少しずつ大きくする
- フォント：M PLUS Rounded 1c（タイトルは Black 900、テロップは ExtraBold 800）
- タイトル枠：白地・マゼンタ #E4007F の12px枠・角丸18px・マゼンタの文字84px・2〜3行、y=200〜430
- テロップ枠：白地・黒 #141414 の6px枠・角丸16px・文字78px・1枠2行・1行11字まで。横幅は文字に合わせる
- 文字の色：説明＝青 #1A1AC8／日付・年齢・肩書き＝緑 #0B7A2E／強調・数字・決め＝赤 #C8102E（2色目はオレンジ #D9480F）／ツッコミ＝紫 #7708AF
- 置く範囲：上テロップ y=97〜308、写真 y=386〜1533（横幅最大970px）、下テロップは写真の下の端に重ねる（下の端 y=1552）。y=0〜90 と y=1560〜1920 は空ける
- 出典ラベル：各写真の左上に「出典：〇〇」（白文字28px・半透明の黒地・角丸8px）。2枚比較で左上に「昔」「今」のラベルを置くときは左下
- フッター・ロゴ・区切りカード・マスコットは**なし**。チャンネル名も画面に出さない

**カットの種類**（spec.json の clips[].type の案）
- `title`：冒頭画面。パターンA（縦に昔→マゼンタの↓→モザイクの今）／B（横に昔→赤い→→モザイクの今）／C（1枚まるごとモザイク）。モザイクはブロック40〜60px
- `single`：写真1枚＋上テロップ＋下テロップ（下はカット開始の約2秒後に出す）
- `reveal`：公開カット。下テロップを2つ、あとのものを上に積む
- `compare`：2枚比較（上下に分ける。「昔」「今」のラベル）
- `wide`：横長のキャプチャ（上下に背景を見せる）

**音**
- 読み上げ：VOICEVOX の**青山龍星**1人（2026-11-07にユーザーが決定）。高さ・抑揚は元のまま、速さだけベンチマーク①1位に合わせた。2人の声（九州そら＋青山龍星）を試したが、声色に違和感があるので戻した（2026-11-08 ユーザー「声はもとの青山でいい。声色がおかしい、違和感」）。テロップを全部そのまま読む（上→下の順）
- 効果音：ベンチマーク①1位と同じ効果音ラボの音・同じ置き方（冒頭＝和太鼓でドドン、1つおきのテロップ＝小パンチ・パフ、公開と最後のカットの上テロップ＝きらーん1）。BGMは入れない
- 概要欄に声と効果音のクレジットを入れる（「・読み上げ：VOICEVOX:青山龍星」「・効果音：効果音ラボ」）

**サムネ**
- 冒頭画面（カット1）をそのままサムネにする。Xの写真を使うときは、反応集と同じくサムネにもクレジットを焼き込む

**納品前チェック（predeliver の答え合わせ速報版）**
- `scripts/predeliver.py` でまとめて確かめる（kotaeawase-douga スキル 8章）
- 合計27〜31秒（ベンチマーク①1位は29.2秒）・7カット・テロップ14個。公開カットの位置（型Aは13〜16秒、型Bは7〜12秒、型Cは10〜13秒）
- テロップの字数（スペースは数えず、半角の英数字は2字で全角1字）。1つのテロップ6〜15字、合計約175字
- 読み上げに数字・英字が残っていないか（誤読しない読みにする）
- spec.json と音声の新しさ（テロップを直したら合成し直す）
- 画像の重複（sim_images.py）
- 出典ラベルと概要欄の出典が、画像の出どころ.json と一致しているか

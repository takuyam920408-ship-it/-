## 2. 再生数が高い動画の共通点

- **1動画1テーマ**: 複数の作品を薄く紹介するより、1作品・1エピソードに絞った方が視聴維持率が上がる
- **既知の話題性を利用**: 完全新規の無名作品より、「知ってるようで知らない」「原作が有名」など一定の認知がある題材の方が初速が出やすい
- **結末を隠しながら気配だけ見せる**: サムネ・タイトルで核心の一歩手前まで見せ、本編で回収する構成
- **強い感情ワードとの紐付け**: 「衝撃」「神」「泣ける」「ゾッとする」「後味が悪い」など感情を一語で表すラベルが再生数上位動画に共通
- **シリーズ化・投稿頻度**: 同じフォーマット（例：打ち切り漫画シリーズ第◯回）を継続することでチャンネル自体のリピート視聴・登録に繋がる

## 3. タイトル／冒頭フックの特徴

- **疑問形・断定形の強い言葉**: 「なぜ？」「まさか」「これ気づいた人天才」など、続きが気にならざるを得ない言い回し
- **数字の活用**: 「1話だけで」「3分で」「5選」など具体的数字で内容量と時短感を提示
- **伏せ字・引っ張り**: 核心のワードだけを隠す（「〇〇な結末」）ことでクリック・最後まで見る動機を作る
- **文字数は短く・直感的**: ショートのタイトルは長文よりも一目で内容がわかる簡潔さが重要（目安30文字以内）
- **冒頭0〜3秒でクライマックスの一部を先出し**: 「見る理由」を即提示することで離脱を防ぐ（逆算構成）

## 4. 伸びやすい人物属性（ナレーター・語り手）

- **顔出し不要**: このジャンルの最大の参入障壁の低さ。ナレーション・テロップのみで完結できる
- **感情豊かな女性ボイス／AI音声の需要増**: 「この声だから見る」というファンがつくケースが多く、声の抑揚・間の取り方が視聴維持率に直結
- **共感型・友人に話すような口調**: 解説者然とした硬い語りより、視聴者と同じ目線で驚いたり感情移入したりする語りが好まれる
- **辛口・煽り系実況の需要もあり**: 5ch反応系・スカッと系では、あえて毒舌・煽り気味なコメントを挟むスタイルが刺さる層が存在

## 5. 視聴維持率が高い構成

標準的な高維持率テンプレート（目安：85%以上で合格、90%超でバズ帯）:

1. **フック（0〜3秒）**: 結末・衝撃シーンの一部を先出し＋テロップで要点提示
2. **導入（3〜8秒）**: 作品・状況設定を最小限で説明（説明過多にしない）
3. **本編（〜尺の80%）**: 2〜3秒に1カットのテンポでシーン転換。山場を複数用意し飽きさせない
4. **オチ／核心（終盤）**: フックで匂わせた結末を回収。ここで感情のピークを作る
5. **CTA（最後の1〜2秒）**: 「続き気になる人はコメントで」「フォローで続編」など軽い一言のみ

**離脱ポイントの回避**: 冒頭の挨拶・前置きが長い、テンポが単調（カット割りが少ない）、結末が予測できてしまう構成は離脱率が上がるため要注意。

## 6. 再現しやすい企画フォーマット（テンプレート化）

すぐに量産できる型として以下5つが再現性が高い:

1. **ランキング型**「〇〇な漫画3選＋一番衝撃的なオチ」— リスト形式で維持率と検索流入を両取り
2. **ダイジェスト型**「全〇話を1分で」— 有名作の総集編的紹介、既存ファンの再訪も狙える
3. **反応差し込み型**「みんなの反応と一緒に読む」— 5ch/Twitter等の反応をテロップで差し込み、没入感を演出（ユーザーの反応集フォーマットと親和性大）
4. **発掘型**「知らないと損する隠れた神漫画」— 検索需要ベースのタイトルで安定した流入
5. **IF・考察型**「もしも〇〇だったら」— 原作にない切り口で既存ファン以外にも興味を広げる

## 出力: バズ動画の共通点（まとめ）

1. 1動画1テーマに絞り、結末・核心を軸に構成している
2. サムネ・タイトルで感情ワード（衝撃／神／泣ける／ゾッとする）を明示している
3. 冒頭3秒で「見る理由」を提示する逆算構成になっている
4. 2〜3秒に1カットのテンポで視覚的に飽きさせない
5. コメント欄で語りたくなる余地（賛否・共感ポイント）を残している
6. 顔出し不要・感情豊かな声（ナレーター）で継続視聴を作っている
7. シリーズ化されており、チャンネルとしてのフォーマットが確立している

# コミュニティ投稿アシスタント

URL を1本貼るだけで、**画像収集 → 投稿画像の加工 → 投稿文の生成** までを自動でやる
ローカル Web アプリ。最後の「Studio に貼って投稿/予約」だけ人間がやる半自動ツール。

**AI（LLM）は一切使っていません。** 使っているのは辞書マッチ・正規表現・テンプレート差し込み・
ルールベースのスコアリングだけなので、API 費用ゼロ・出力のブレなし・オフラインでも動きます。

---

## なぜ「半自動」なのか

YouTube Data API v3 には**コミュニティ投稿を作成するエンドポイントが存在しません**。
公式 API で投稿できない以上、「ボタン1つで投稿完了」は規約を守る限り作れません。

一方、YouTube Studio 側にはコミュニティ投稿の**予約機能**があります。
そこでこのアプリは「投稿ボタンを押す直前まで」を全部やります。
週1回まとめて生成 → Studio で貼り付けて予約、で1週間分が片付きます。

> Playwright 等で Studio を自動操作すれば完全自動化は技術的に可能ですが、
> 公式 API 以外の自動アクセスは YouTube 利用規約違反です。このアプリはやりません。

## セットアップ

```bash
pip install -r requirements.txt
./run.sh              # Windows は run.bat
```

ブラウザで http://127.0.0.1:8000 を開く。

日本語フォントが見つからないと画像の文字が豆腐になります。
自動で探す場所は `app/config.py` の `FONT_CANDIDATES`（macOS のヒラギノ、Windows のメイリオ/游ゴシック、
Linux の IPA ゴシック）。別のフォントを使いたいときは環境変数で指定:

```bash
CPA_FONT=/path/to/your-font.ttf ./run.sh
```

## 使い方（画面の1〜6）

1. **URL を取り込む** — アニメ公式サイト / ニュース記事の URL を貼る。自分の動画 URL は任意（`{動画URL}` に入る）
2. **画像を選ぶ** — スコア順に並んだ候補から1枚クリック。ロゴ・アイコン・広告バナー・小さすぎる画像は自動で除外済み
3. **抽出結果を確認・修正** — 作品名 / 話数 / キャラ名。**ここが人間のチェックポイント**（後述）
4. **投稿画像に加工** — サイズ・トリミング位置・左上バッジ・下帯キャプションを選んで生成、保存
5. **投稿文を生成** — テンプレートから3案。気に入った案をコピー
6. **投稿して記録** — Studio で貼り付け・予約したあと「投稿済みとして記録」。次回以降のネタ被り防止に使われます

---

## 重要な制約：AI なしでは「画像の中身」は読めません

「画像に合った投稿文」を機械が作るには、画像を見て理解する必要があります。AI なしでは不可能です。

代わりにこのアプリは、**画像と一緒に付いてきたテキスト**から文面を組み立てます:

- `alt` 属性 / `<figcaption>` / 画像直前の見出し
- ページの `<title>` `og:title` `og:description`
- URL のパス（`/anime/yanineko/12/` → 作品=ヤニねこ、話数=12）

実用上はこれでほぼ足りますが、**画像とテキストがズレることはあります**。
だから画面3でプレビュー確認を1ステップ挟んでいます。ここは省略しないでください。

埋まらなかったスロットは空のままにし、そのスロットを `requires` に持つテンプレートは
候補から外れます（**埋まっていない値を推測で書かない**設計）。

## カスタマイズ

育てる価値があるのはこの2ファイルだけです。編集後は画面をリロードするか
`POST /api/reload` で再読み込み（サーバー再起動は不要）。

### `data/dictionary.yaml` — 作品辞書

```yaml
works:
  - id: yanineko          # 履歴DB上のキー
    name: ヤニねこ         # {作品名}
    tag: ヤニねこ          # {作品名タグ}（# は書かない）
    aliases: [ヤニ猫, yanineko]   # 表記ゆれ。マッチ判定に使う
    characters: [ヤニねこ, シャブねこ]  # {キャラ名}
    phrases:              # {感想フレーズ}（この作品専用）
      - "今回も情緒ぐちゃぐちゃにされた…"
generic_phrases:          # 作品が特定できなかったとき用
  - "コメント欄の温度が高い回でした"
```

**ここを増やすほど抽出精度と文面の質が上がります。** 最初の投資先はここ。

### `data/templates.yaml` — 投稿文テンプレート

```yaml
templates:
  - id: shinsaku_kokuchi
    type: 新作告知
    requires: [作品名, 話数]   # 全部埋まっていないとこのテンプレは使われない
    weight: 3                 # 抽選の重み。伸びたテンプレの数値を上げる
    text: |
      【{作品名}】{話数}話の反応まとめました！
      {感想フレーズ}
      ▶ {動画URL}
      #{作品名タグ} #反応集
```

使えるスロット: `{作品名}` `{作品名タグ}` `{話数}` `{キャラ名}` `{タイトル}`
`{元記事URL}` `{動画URL}` `{サイト名}` `{感想フレーズ}`

## 画像スコアリングのルール（`app/scoring.py`）

| 加点 | | 除外 | |
|---|---|---|---|
| `og:image` | +50 | URL に `logo` `icon` `banner` `ad` など | 即除外 |
| `twitter:image` | +40 | 短辺 200px 未満 | 即除外 |
| 解像度（面積） | 最大 +40 | 縦横比 3:1 超（バナー形状） | 即除外 |
| 作品名が alt / URL に一致 | +20 | | |
| `main` `key` `visual` `kv_` などのファイル名 | +12 | | |
| 投稿向きの縦横比（1:1〜1.9:1） | +10 | | |
| キャプションあり / alt あり | +8 / +5 | | |

誤爆したら `EXCLUDE_PATTERNS` / `BOOST_PATTERNS` を足してください。

## 履歴とネタ被り防止（`data/history.db`）

「投稿済みとして記録」を押すと SQLite に保存され、次から効きます:

- 同じ元記事 URL を90日以内に使っていたら**警告**を出す
- 使用済みの画像には候補一覧で「使用済み」バッジ
- 直近8件で使ったテンプレは抽選の重みを 1/5 に下げる
- 同じ作品で直近10件に使った `{感想フレーズ}` は選ばない

## 著作権について

他サイトから収集した画像をそのまま投稿に使うのは、公式配布素材・プレスキット以外は
リスクがあります。このアプリは画像を**集めて見せるところまで**しかやりません。
使ってよい画像かの判断は利用者の責任です。

安全側に倒すなら、画像源を自分の動画のサムネ/フレームにするのが確実です。
その場合は `app/adapters/` に YouTube 用アダプタを足して `ADAPTERS` に登録すれば、
残りの処理（スコアリング・加工・文面生成・履歴）はそのまま使えます。

なお取得時は **robots.txt を尊重**します。拒否されているサイトはエラーになります
（どうしても必要なときだけ `CPA_IGNORE_ROBOTS=1`。判断は自己責任で）。

## 構成

```
app/
  main.py              FastAPI ルーティング
  config.py            パス・フォント解決・環境変数
  models.py            ImageCandidate / PageMeta / Slots / Draft
  adapters/
    base.py            URL → アダプタの振り分け
    generic_news.py    OGP + <img> + srcset + 遅延ロード属性の収集
  imagefetch.py        画像DL・キャッシュ・実寸測定（並列）
  scoring.py           ルールベースのスコアリング
  extract.py           辞書マッチ + 正規表現でスロット抽出
  textgen.py           テンプレート差し込み・重み付き抽選
  compose.py           Pillow でトリミング・帯・バッジ
  db.py                SQLite 履歴
data/
  dictionary.yaml      作品辞書      ← ここを育てる
  templates.yaml       投稿文テンプレ ← ここを育てる
web/                   単一ページ UI（素の HTML/CSS/JS、ビルド不要）
output/                生成した投稿画像
```

## 環境変数

| 変数 | 既定 | 説明 |
|---|---|---|
| `CPA_FONT` | 自動検出 | 使う日本語フォントのパス |
| `CPA_HTTP_TIMEOUT` | `15` | 取得タイムアウト（秒） |
| `CPA_MAX_IMAGE_PROBES` | `24` | 実寸を測る画像の上限枚数 |
| `CPA_IGNORE_ROBOTS` | `0` | `1` で robots.txt を無視 |
| `CPA_USER_AGENT` | 専用 UA | 送信する User-Agent |

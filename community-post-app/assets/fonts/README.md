# フォントの置き場

画像に焼き込む文字は **けいふぉんと** を使います。
このフォルダに `keifont.ttf` を置くと、アプリが自動で使います。

## 入れ方

1. 配布元 https://font.sumomo.ne.jp/font_1.html から zip をダウンロード
2. 解凍して出てくる `keifont.ttf` を、**このフォルダに置く**
3. アプリの画面を再読み込み（サーバーの再起動は不要）

Mac なら `keifont.ttf` をダブルクリックして Font Book でインストールしてもかまいません。
その場合は `~/Library/Fonts/keifont.ttf` に入るので、アプリはそちらも自動で見つけます。

## 見つけ方の優先順位

1. 環境変数 `CPA_FONT` で指定されたフォント
2. このフォルダの `keifont.ttf`（ファイル名に `kei` を含む .ttf/.otf/.ttc でも可）
3. `~/Library/Fonts/keifont.ttf` / `/Library/Fonts/keifont.ttf` / Windows のフォントフォルダ
4. このフォルダにある任意の日本語フォント
5. OS 標準の日本語フォント（ヒラギノ、メイリオ、IPA ゴシックなど）

けいふぉんと以外が使われているときは、アプリの画面上部に警告が出ます。

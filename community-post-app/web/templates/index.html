コミュニティ投稿アシスタント

URL を貼る → 画像を選ぶ → トリミング＆露出を黒モザイク → 黒帯の解説文 → 文面をコピー → Studio に貼って予約。AI は使っていません。

1URL を取り込む

robots.txt を尊重します。取得できないサイトは手動保存に切り替えてください。

2画像を選ぶ

3抽出結果を確認・修正

空欄のスロットを requires に持つテンプレートは使われません（埋まっていない値は書かない設計です）。

4トリミング＆露出を黒モザイク 必須

自動検出が拾えるのは「肌色のかたまり」だけです。顔も検出されますし、見落としもあります。 必ず目で確認し、ドラッグで追加 / 枠をクリックで削除して仕上げてください。
自動検出 手動で追加

5黒帯の解説文 必須

6投稿文を生成

7投稿して記録

文面をコピーして画像を保存したら、Studio で貼り付け・予約してからここを押してください（次回以降のネタ被り防止に使います）。

# ⓪ リサーチ：FANZAで紹介する作品を探す

台本は「FANZAで最新の評価が高い漫画を探す → その作品のストーリー文（作品紹介文）を資料として取り込む → 構成する」の順で作る。ユーザーが作品を指定してきた場合は、このリサーチは飛ばして1章に進む。

## 1. FANZAにたどり着く方法（使える順）

1. **ブラウザ操作ツール**（アプリ内ブラウザ、Claude in Chrome など）が使える場合：FANZAの同人・電子書籍のコミック一覧を開き、評価の高い順・新着順で見る。使う前に、そのツールのスキル（built-in-browser／chrome-browser）を読む。年齢確認の画面が出たら、ユーザー本人に通してもらう
2. **DMMのアフィリエイトAPI**の API ID とアフィリエイトID をユーザーからもらっている場合：APIで候補（タイトル・作品ページURL・評価・レビュー件数・発売日・ジャンル）を集め、ストーリー文は作品ページから取る
3. **どちらも使えない場合**（ネットワークの制限でFANZAに接続できない環境など）：ユーザーに、候補作品のページURLと作品紹介文（ストーリー文）をそのまま貼ってもらう

接続できない場合は、何が使えなかったか（例：dmm.co.jp に接続できない）をユーザーに伝えてから3に切り替える。

## 2. 候補の選び方

次の3つをすべて満たすものを候補にする。数値は目安で、ユーザーが指定したらそちらを優先する。

- **最新**：発売から3か月以内
- **評価が高い**：レビューの平均点が高い（目安4.5以上）うえで、レビュー件数がある程度ある（目安10件以上）。件数が少ない満点作品より、件数が多い高評価作品を上にする
- **YouTubeで紹介できる**：次の「除外する作品」に当てはまらない

### 除外する作品

- 学生・子どもに見えるキャラが中心の作品（学園・制服もの、幼く見える絵柄、それに当たるジャンルタグが付いたもの）。設定上は成人でも、見た目や舞台が学生なら除外する。子どもの性的な扱いにつながる紹介はしない
- 無理やり・合意のない行為が中心の作品（ジャンルタグや紹介文で判断する）。匂わせでも紹介しにくく、YouTubeの規約上のリスクが高い
- 性的な場面以外に展開や見せ場がない作品。台本は「匂わせ」までしか書けないので、ストーリーで引きがないと紹介が成り立たない
- 女性向け・BL・TLの作品（チャンネルのターゲットは男性視聴者のため）

### 伸びやすい作品（優先する）

- ストーリー文だけで「属性 × 意外な一面」のギャップが作れる（例：鉄壁の上司の裏の顔、完璧な人の秘密）
- 登場人物が成人だと分かる設定（社会人・大学生・人妻・上司と部下など）
- 秘密がバレる・条件を出される・立場が逆転するなど、話が動く出来事がある

## 3. 候補をユーザーに見せる

**10作品**を表で出し、どれで台本を作るかユーザーに選んでもらう。選ぶのはユーザーなので、こちらで勝手に1つに決めない。返事が来るまで台本作りに進まない。

| # | 作品名 | 作者・サークル | 発売日 | 評価（平均／件数） | ジャンル | 切り口の案（タイトル案） | 作品ページ |
|---|---|---|---|---|---|---|---|

- 並び順は、評価が高くレビュー件数も多いものを上にする
- 「切り口の案」は、4章のタイトルの型に当てはめた一言にする（例：鉄壁の女上司の裏の顔が可愛すぎた）
- 評価・件数・発売日・ジャンルは、見たページ（またはAPI）の値をそのまま書く。推測で埋めない
- 条件に合う作品が10作品に届かないときは、見つかった分だけ出し、足りなかったことと理由（例：3か月以内で条件に合うのは7作品だった）を伝える。条件をゆるめて10作品にするか（例：発売6か月以内に広げる）はユーザーに聞く
- ユーザーが複数を選んだら、1作品ずつ順番に台本を作る

## 4. ストーリー文を資料として取り込む

選んだ作品の作品紹介文（ストーリー文）を、作品ページから**そのまま**資料として控える。あわせて、作品名・作者・発売日・作品ページURLも控える。

- これが1章の「作品の資料」になり、信頼担当が事実の基準として使う。台本はストーリー文に書かれている範囲だけで組み立てる
- 作品紹介文は露骨な表現を含むことが多い。台本・概要欄には、その言葉を使わず匂わせに書き直す（8章の言い換えと守ること）
- 作品紹介文をそのまま概要欄に貼らない（他人の文章のため）。概要欄の作品紹介は、自分の言葉で1〜3行に書き直す
- サンプル画像の中身を台本やカット割りに使う場合は、見たページの内容だけを使う。画像のダウンロードはせず、動画に使う素材の用意と、使ってよいかの確認（アフィリエイトの規約など）はユーザーに任せる
- 誘導先URL（アフィリエイトリンク、またはそれを載せたX投稿・短縮URL）はユーザーに確認する。FANZAの作品ページURLをそのまま概要欄に使わない（アフィリエイトIDが付いていないと収益にならないため）

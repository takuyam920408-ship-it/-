# 漫画紹介ショート 台本の共通点分析

調査日：2026-09-27
対象：前回まとめた「ベンチマーク候補_漫画紹介ショート」のうち、概要欄にX等への導線がある49チャンネル

- 台本の中身：人気ショートの自動字幕（29本・13チャンネル）から書き起こし
- 尺：45本分の尺データ
- タイトル（冒頭で読み上げるフックと同じ文言）：約4,200本
- 概要欄：約60本分の文面

※ 自動字幕を元にしているため、固有名詞などには聞き取りの誤りがあります。
※ YouTubeの画像サーバーが調査環境から使えなかったため、画面構成（テロップの位置、画像の見せ方）は確認できていません。

---

## 結論：型は2つしかない

| | A. ストーリー要約型 | B. 1コマ・5秒ループ型 |
|---|---|---|
| 尺 | **38〜60秒（中央値53秒）** | **5〜6秒** |
| 音声 | ナレーション＋キャラのセリフ（VOICEVOXなど） | 読み上げなし（BGMのみ） |
| 台本の中身 | 作品のあらすじを語り、一番いいところで切る | 画面の一言テロップ＝タイトルだけ |
| 伸ばし方 | 「続きが気になる」で概要欄に送る | 何度も見返させて（ループ）再生数を稼ぐ |
| 代表 | 漫画ムラ（ベンチマーク元）、夜の栞、オトナのマンガ部屋、今夜のおかず、運命の1冊、チェリマンガ、大人の漫画BOOK | おすすめバズ漫画、今宵のバズ同人、同人マンガタイムズ、同人マンガワールド、バズマンガ倉庫、バズ漫画、夜の漫画クラブ、俺のひとコマ |

ベンチマーク元の漫画ムラは**A型**です。A型の中でも、2ch風のツッコミを入れる「反応集」寄りの書き方をしています。

---

## A型（ストーリー要約型）の共通点

### 数値

| 項目 | 中央値 | 範囲 |
|---|---|---|
| 尺 | 53秒 | 32〜60秒 |
| 読み上げ文字数 | 約380字 | 218〜460字 |
| 話す速さ | 1秒あたり約7字 | 5.3〜8.1字（伸びているチャンネルはほぼ7字以上） |
| 締めの「続きは概要欄」が始まる位置 | 終わりの約3秒前 | 24本中20本が言葉でCTAを入れている |

→ 普通の話し方（1秒あたり5字前後）よりかなり**早口で詰め込む**のが共通点です。

### 台本の流れ（ほぼ全チャンネル共通）

| 時間の目安 | パート | 中身 | 実例（自動字幕より） |
|---|---|---|---|
| 0〜3秒 | ①フック | **タイトルをそのまま読み上げる**。頭に「衝撃」「悲報」を付けることもある | 「恩人にイキ地獄を味わわせてやった結果」「衝撃 完璧ヒロインの裏の顔が気持ちよすぎた」「悲報 天才博士の発明方法がやばすぎるんだ」 |
| 3〜5秒 | ②最初のセリフ | **すぐにキャラのセリフを1つ入れる**（告白・叱る・煽るなど）。10チャンネル中7チャンネルが5秒以内に入れている | 「私と付き合ってくれませんか？」「離れていても忘れないで」「うちと付き合わん？」 |
| 5〜20秒 | ③設定 | ナレーションで人物紹介。**平凡な主人公 × 属性のはっきりしたヒロイン** | 「クラスの一軍女子に告白され付き合うことになった主人公」「道場を仕切る師範の彼女 実力は日本一」 |
| 20〜45秒 | ④展開 | 「しかし」「そんなある日」「だが」で事件を起こし、**セリフのやり取り2〜4往復**をナレーションでつなぐ | 「そしてある日 ついに男は彼女に別れを切り出してしまうのだ」 |
| 45〜52秒 | ⑤クライマックスの直前 | **核心の一歩手前**まで話して止める | 「彼女は予想外の行動に出る」「その瞬間 彼女の様子が一変し」「最後に欲しがるもの それはまさかの」 |
| 最後の3秒 | ⑥締め | 「この続きは概要欄をチェックして」または**文の途中でぶつ切り**（ループさせる） | 「続きは画面を長押しして説明をタップでチェックして」 |

### その他の共通点

- **ヒロインの属性とのギャップが本題**：完璧ヒロイン×裏の顔、一軍女子×地味男、美人空手家×生徒に敗北、天才少女博士×とんでもない発明方法など。「真面目・高嶺の花・強い」人物の意外な一面が王道です。
- **直接的な言葉は伏せ字・隠語で言い換える**：「メロン」「マシュマロ」「チュピチュピパチパチ」「〇〇」「シたら」「イキ地獄」など。（自チャンネルの「エロ→江戸」「えっち→ムホホ」ルールと同じ考え方）
- **ナレーションは三人称・説明口調**（「〜な主人公」「〜する女」「〜なのだ」）で、**セリフは会話口調**。この切り替えでテンポを作っています。
- **ハッシュタグ**はほぼ `#漫画 #漫画紹介` の2つだけです。

### 漫画ムラ（ベンチマーク元）だけの特徴＝反応集らしさ

- 冒頭のフックが**2ch風のスレタイ**：「ワイが絶対に彼女と別れられない理由がこちら」「好きな人を取られたワイ 秘密兵器を開発し逆転勝利してしまう」
- **タイトルは読み上げより短い一言**：「彼女と別れられないワイ」「ただの勝ち組」「陰キャさんの名刀ww」「ハズレだと思ったら…」
- ナレーションの合間に**ツッコミの一言**を入れる（1本に2〜4回）：
  - 「負け惜しみ草」「贅沢な悩みやな」「そらそうよ」「大発明じゃねえか」「結果決まってて草」
  - （大人の漫画BOOKも少し使う：「人生楽しいな」「もはやホラーだな」）
- **締めで「続きは概要欄」と言わない**：核心の直前で切れるので、そのまま頭に戻ってループする。導線は概要欄の「作品はこちら⤴︎（2回タップで選択➡️開く）」だけで行っている
- 音声はチャンネル説明によると VOICEVOX（四国めたん・青山龍星・ずんだもん）の3人

## B型（1コマ・5秒ループ型）の共通点

- **尺は5〜6秒**。読み上げはなく、BGMだけ（今宵のバズ同人は全動画で同じ曲）
- 台本にあたるのは**タイトル（＝画面の一言）と概要欄の作品紹介**だけ
- タイトルの型は4つ：

| 型 | 例 |
|---|---|
| ツッコミ・感想 | 「態度と好感度バグってる」「色変わりすぎ」「どういうこと？」 |
| 見返させる謎かけ | 「これは下でしょ」「理由はヒミツ」「結局どっち派でも得するタイプ」「持ち物変わってる＝交わった？」 |
| 属性＋一言 | 「男は顔だけじゃない」「太らせて食べるタイプ」「警官の本性」「人生2周目のガキ」 |
| シリーズ化 | 「人気漫画のアニメと実写化比較！②」 |

- 5秒で終わるので何度もループされ、1本あたりの再生数が伸びやすい。10万回再生を超える本数が多いチャンネル（同人マンガワールド23本、今宵のバズ同人22本、おすすめバズ漫画38本）はほぼこの型

---

## 概要欄（導線）の共通点

A型・B型とも同じ構成です。

```
（1行目）短縮URL（x.gd）か X / Bluesky の投稿URL

↑URLを長押ししてリンクを開く
（iPhoneはダブルタップ）
※長押しで選択できない場合は、スクショした画面からURLを長押し

【作品紹介】（または＜どんな作品？＞／📝作品概要／【説明】）
あらすじ1〜3行。結末は伏せて「〜とは…？」「〜が気になる作品」で締める
```

- **URLは必ず1行目**（スマホの概要欄で最初に見える位置）
- アプリ内でリンクが開けない前提で、**開き方を毎回書く**
- 作品紹介は「〜が気になる作品です」「〜とは…？」「〜…!?」で締めるのが定番

## タイトル（＝冒頭のフック）のデータ

- **文字数**：中央値14字。10万回再生を超えたものも13字で、短めが基本
- **言葉選びだけでは差がつかない**：「ヤバすぎた」「最高すぎた」「した結果」「悲報」などの言葉ごとに、同じチャンネル内での伸び方を比べたところ、差は±1割程度しかない
- **差がつくのは設定のギャップの強さ**。各チャンネルの普段の再生数の何十倍も伸びた動画のタイトルは、どれも「属性 × 意外な行動」が一目で分かるものだった：

| 普段の再生数の何倍か | 再生数 | タイトル |
|---|---|---|
| 324倍 | 124万 | 大きすぎるお母さんの秘密がヤバすぎた |
| 243倍 | 183万 | 別の男を作った彼女を教育したら最高すぎた |
| 146倍 | 110万 | 生徒に敗北した美人空手家が最高すぎた |
| 124倍 | 230万 | 恩人にイキ地獄を味わわせてやった結果 |
| 67倍 | 113万 | 【悲報】天才少女博士の発明方法がとんでもなさすぎるwwwwww |

## 自チャンネル（バズらないと【反応集】）の台本ルールとの違い

今の反応集スキルのルールとは、次の点が逆になります。漫画紹介を始める場合は**別フォーマットとして扱う**のがおすすめです。

| 項目 | 今の反応集ルール | 漫画紹介（A型） |
|---|---|---|
| 尺 | 25〜33秒、40秒超は短縮 | **50秒前後が標準**（あらすじを語り切る必要があるため） |
| 冒頭 | 「〜が話題に」で締める | タイトルを読み上げる／2ch風スレタイ |
| 締め | 行動を求めない断定・共感型 | **「続きは概要欄」が必須**（ここが収益の入口） |
| 反応コメント | 反応を3つ | ナレーションの合間にツッコミを2〜4回 |
| 禁止ワードの言い換え | エロ→江戸、えっち→ムホホ | 同じ考え方（隠語・伏せ字）でそのまま使える |

# 記入例

どれも架空の作品で書いた例。実際の台本では、ユーザーから渡された作品の情報だけを使う。

---

## 例1　A型（CTAで締める）

```
【型】A（ストーリー要約型／CTA締め）
【タイトル】
完璧な生徒会長の裏の顔がヤバすぎた
【台本】
［ナレ］
完璧な生徒会長の裏の顔がヤバすぎた
［会長］
放課後 生徒会室に来なさい
［ナレ］
成績トップで容姿端麗
全校生徒の憧れである生徒会長の白石さん
一方の主人公は教室の隅でゲームばかりしている陰キャ男子
そんな彼がある日突然 会長に呼び出されたのだ
［ツッコミ］
没収確定で草
［ナレ］
恐る恐る生徒会室へ向かうと
［会長］
昨日の夜 ランクマッチで私を倒したのはあなたね？
［主人公］
え なんでそれを
［ナレ］
なんと会長の正体は
全国ランキング2位の廃人ゲーマーだったのだ
［ツッコミ］
人は見かけによらんな
［会長］
負けっぱなしは性に合わないの
今日から毎日付き合ってもらうわよ
［ナレ］
断れるはずもなく
その日から放課後は毎日 会長と二人きり
負けるたびに悔しがる会長の姿は 教室では絶対に見られないものだった
［ツッコミ］
ご褒美やんけ
［ナレ］
こうして始まった放課後の秘密の特訓
しかし会長の本当の目的は ゲームだけではなかった
ある日 特訓のあとに会長が差し出した一枚の紙
そこに書かれていたのは まさかの
［ナレ］
この続きは概要欄をチェックして
【ハッシュタグ】
#漫画 #漫画紹介
【概要欄】
https://x.gd/〇〇〇〇〇

↑URLを長押ししてリンクを開く
（iPhoneはダブルタップ）
※長押しで選択できない場合は スクショした画面からURLを長押し

【作品紹介】
全校生徒の憧れである完璧な生徒会長が、放課後だけ見せる意外な素顔。
ゲームから始まった二人の関係の行方とは…？

※アフィリエイト広告を利用しています
```

ポイント
- ①フックとタイトルが同じ文言
- 2行目で会長のセリフ（5秒以内）
- 「完璧な生徒会長 × 廃人ゲーマー」のギャップが本題
- ツッコミ3回、「そこに書かれていたのは まさかの」で核心の手前で止めている

## 例2　A型（漫画ムラ型・ぶつ切りで締める）

```
【型】A（ストーリー要約型／ぶつ切り締め）
【タイトル】
弁当を作ってもらえるワイ
【台本】
［ナレ］
残業続きのワイ 無口な後輩に毎日弁当を作ってもらっている理由がこちら
［後輩］
先輩 これ余ったんで
［ナレ］
ブラック企業で働く主人公は 毎晩終電まで残業する社畜
コンビニ飯すら食べる暇がない日々を送っていた
そんな彼の隣の席にいるのが 入社2年目の後輩 小森さん
仕事は完璧だが 無口で誰とも雑談しないため社内では近寄りがたい存在だった
［ツッコミ］
ワイの職場にもおるわ
［ナレ］
そんなある日 机の上に置かれていたのは手作りの弁当
［主人公］
え これ小森さんが？
［後輩］
作りすぎただけです 捨てるのもったいないので
［ナレ］
しかしその日から 弁当は一日も欠かさず届くようになった
しかも毎回 主人公の好物ばかりが入っているのだ
［ツッコミ］
作りすぎの量ちゃうやろ
［ナレ］
さすがに気になった主人公は 思い切って理由を聞いてみることに
［主人公］
なんで毎日作ってくれるの？
［ナレ］
すると小森さんは顔を真っ赤にして うつむいたまま一冊のノートを差し出した
そこに書かれていたのは
［ツッコミ］
結果決まってて草
【ハッシュタグ】
#漫画 #漫画紹介
【概要欄】
https://x.gd/〇〇〇〇〇

作品はこちら⤴︎（2回タップで選択➡️開く）
※長押しで選択できない場合は スクショした画面からURLを長押し

【作品紹介】
無口で近寄りがたい後輩が、毎日こっそり届けてくれる手作り弁当。
そこに込められた本当の理由とは…？

※アフィリエイト広告を利用しています
```

ポイント
- フックは2ch風スレタイ「〜なワイ 〜な理由がこちら」、タイトルはさらに短い一言
- 締めで「続きは概要欄」と言わず、ツッコミで切って頭に戻す

## 例3　B型（1コマ・5秒ループ型）

依頼の想定：「3コマで、朝・昼・夜と部下の机のお菓子が増えていき、最後のコマで鬼上司がこっそり置いていたと分かる1ページ漫画。タイトルと概要欄を作って」

```
【型】B（1コマ・5秒ループ型）
【タイトル案】
1. 鬼上司の本性
2. お菓子が増える理由はヒミツ
3. 厳しさと優しさバグってる
【画面・音】
尺5〜6秒／BGMのみ／1ページ全体を表示（最後のコマの上司が見切れないように）
【ハッシュタグ】
#漫画 #漫画紹介 #shorts
【概要欄】
https://x.gd/〇〇〇〇〇

↑URLを長押ししてリンクを開く
（iPhoneはダブルタップ）
※長押しで選択できない場合は スクショした画面からURLを長押し

【作品紹介】
朝・昼・夜と、なぜか少しずつ増えていく机の上のお菓子。
いつも厳しい上司の意外な一面が気になる作品です。

※アフィリエイト広告を利用しています
```

ポイント
- 1は属性＋一言型、2は謎かけ型（見返して答えを探させる）、3はツッコミ型
- 謎かけ型は答えがページの中にあるので、ループ再生が起きやすい

# カット割り版の作り方

「バズらないと【反応集】」の編集カット割りスキル（anime-henshuu-cutwari）の画面構成（固定ヘッダー／カットごとのメイン画像＋テロップ／固定フッター）をそのまま使い、中身を漫画紹介向けにしたもの。プレーン版の台本が確定してから作る。

## 画面構成

- **固定ヘッダー**：タイトル（＝冒頭フック）。動画の最初から最後まで画面上部に出続けるので、1回だけ書く
- **メイン画像（カットごとに差し替え）**：漫画のコマ・ページ
- **テロップ（カットごとに差し替え）**：そのカットで読み上げる台本の文言そのもの
- **固定フッター**：作品名のロゴやチャンネル名。案件ごとにユーザーに確認する。分からなければ「〔作品名ロゴ〕」と書いて確認を頼む

## カットの割り方

- 1カットには情報を1つだけ入れる。台本の1行（改行1つ分）を1カットにするのが基本
- 秒数は **テロップの文字数 ÷ 7** で出す（この形式は1秒あたり約7字の早口）。1カットは1.5〜3秒に収め、長い行は2カットに分ける
- 全カットの合計が、プレーン版の推定尺（読み上げ文字数 ÷ 7）と±3秒以内になるようにする
- 話者（ナレ／キャラ名／ツッコミ）をカットごとに書く。VOICEVOXの声の割り当ては案件ごとにユーザーが決めるので、話者名だけ書けばよい

## メイン画像の指定

- 画像の検索・ダウンロードはしない（著作権と利用規約のため、ユーザーと合意済みの方針）
- ユーザーからページ画像が渡されていれば「P3・2コマ目」のように場所で指定する
- 渡されていなければ「〇〇が□□する場面のコマ」と中身で説明し、素材の用意はユーザーに任せる
- セリフのカットには、そのセリフを言っているコマを当てる
- ツッコミのカットは、直前のコマを出したままにする（ツッコミ用のリアクション素材があれば差し替えてもよい）
- ⑤クライマックス直前の最後のカットは、核心の一歩手前のコマにする。核心そのものが写っているコマは使わない（続きを見に行く理由がなくなるため）

## BGM・SE

全カットに書く必要はない。切り替えに意味があるカットにだけ書く。
- ③設定から④展開に入るところ（「そんなある日」など）
- 人物の意外な一面が出る瞬間
- ⑤の直前（BGMを止める、心臓の音などのSEで溜める）
- ぶつ切り締めの場合は、最後のカットでBGMごと切る

## 出力形式

ファイル名は `〔作品名〕_漫画紹介台本_編集カット割り.txt`（プレーン版 `〔作品名〕_漫画紹介台本.txt` と対応させる）。

```
【固定ヘッダー】
〔タイトル〕

【固定フッター】
〔作品名ロゴ・チャンネル名〕

カット1（2.5秒）：〔メイン画像　例：課長がデスクで書類を突き返すコマ〕
話者：ナレ
テロップ：〔台本の文言〕

カット2（2秒）：〔メイン画像〕
話者：課長
テロップ：〔台本の文言〕
BGM/SE：〔必要なときだけ〕

…

合計：約〇〇秒

#漫画 #漫画紹介
```

B型（1コマ・5秒ループ型）は、カット1つだけにする。

```
【固定ヘッダー】
〔選んだタイトル案〕

カット1（5〜6秒）：〔1ページ全体。見切れてはいけないコマの指定〕
話者：なし（BGMのみ）
BGM/SE：〔BGMの雰囲気。ループしても違和感のないもの〕
```
